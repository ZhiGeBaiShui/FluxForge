构建通过不等于本清单已通过。

- 七页翻页、关闭、重新打开，按钮可点击，无旧网格或流源残留。
- 进阶：右侧装液并仅发射一次，按降温→冷萃→升温→左侧接收，之后清理。
- 自动化：六个转角方向正确，两升温、两降温；左下转角最初不存在，流源进入冷萃后放置；形成闭环10秒后清理。
- 冷萃0°C入口和5°C入口可增效；运输途中的环境换热保留。
