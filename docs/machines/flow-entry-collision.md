# 流源入口碰撞与格内交互

逻辑坐标整数为格中心，中心前后半格为边界。

FlowManager 按移动顺序遍历半格事件：
- 边界事件调用 TryEnterCell，普通物品或越界直接销毁；装置通过 IFlowInlet.CanEnter 校验移动方向。
- 进入格子后走过格宽 1/3 时调用 TryProbeCell，只执行反应与路由，不再检查入口合法性。
- 任意事件销毁或截停流源后立即终止本帧路径扫描，后方事件不再执行。

入口与交互点可能分属不同帧。合法进入不会提前触发反应；高速跨过多格仍按路径事件顺序处理。
起点事件不重放，因此从出口中心生成的流源可正常离开。
转向后的偏移若再次跨过本格交互点，DepartureCell 防止重复执行装置反应。
当前格占位查询也按半格边界换算，覆盖物品直接放在流源上的情况。

此变更只调整逻辑运动检测，不修改物品坐标变换、贴图或装置反应公式。

交互点坐标 = 格中心 − 移动方向 × 1/6。需要截停/转向的装置仍对齐中心和既有偏移，保持管道转向与出口位置一致。
