# 流源视觉 v1.0 · 「液滴电荷」

> 一句话：**一颗在 16px 格里流动的液滴**——钝头朝前、亮核偏前；温度写在边缘，含量写在体积，
> 射程是格底的三颗小点，状态用物理直喻（墙 / 两瓣 / 接缝 / 抽吸流）。
> 它不靠宽度表达任何属性，也不靠粒子数量表达"多少"。

## 60 秒读懂

1. **流源是一颗液滴**：前端是 6px 钝口 + 2px 高光 + 2×2 亮核（所以"看到亮的那头就是前面"）；
   后端收成 2px 暗口。全图没有任何 1px 尖角——这是被两次盲测（0/4）逼出来的。
2. **成分看颜色 + 内部纹理**；**温度看边缘**（冷 = 冰蓝边 + 霜点，热 = 橙边 + 蒸汽孔）；
   **含量看整体大小**；**射程看格底三个点**（越少越接近走不动）；**状态看附加结构**
   （墙 / 两瓣 / 亮缝 / 连续抽吸流）。
3. **粗细永远不参与编码**——这是历史上被否决两次的红线。

## 六条信息 → 六条通道

| 信息 | 通道 | 具体编码 | 判据 |
|---|---|---|---|
| 成分 | 混合色（六分量加权；运行时 A 方案） | 6 色（见 `CHANNELS.md`） | 正常 6 组；deutan ≥4 组 |
| 温度 | 边缘带颜色 + 霜点/蒸汽孔 | 冷 = 冷色边 + 霜点；热 = 暖色边 + 孔 + 1px 缺口 | 静态三档可判，包围盒不变 |
| 含量 | 包围盒体积 | 空 6×1 / 少 8×6 / 中 8×8 / 多 12×8 | 档间面积 +500% / +33% / +42% |
| 射程 | 格底 3 个 1px 点 | 亮 3/2/1（y=14, x=4/6/8） | 三档可数；运行时暂未接数据 |
| 状态 | 物理附件/拓扑 | 墙 / 两行空 / 亮缝 + 后缘 V / 连续流 | 5 态静态可读 |
| 方向 | 钝头 + 前脸高光 + 亮核偏前 + 宽窄比 | 全图无 1px 尖角 | 4 向盲测 4/4 |

**不可变规则**：体宽/芯宽/上下厚度永远不参与属性编码；温度不靠动画；含量不靠透明度/粒子数。

## 三条设计原则

1. **皮先于肉**：1px 闭合张力边是"这是一个物体"的唯一保证；含量只改半径，永不把液体打散。
2. **一属性一像素集合**：六个通道的像素互不重叠（`CHANNELS.md` 有冲突矩阵）。
3. **像素尺度铁律**：渐变 = 看不见；要读出的变化必须在 1–2px 步内完成（7px 弧深、45° 台阶）。

## 证据

- 终稿盲测（两轮独立评审，无标注表）：
  - 调色前 **25/25**：方向 4/4、温度 3/3、含量 4/4、射程 3/3、状态 5/5、成分 6/6。
  - 调色后 **23/25**：前五项全对，成分 4/6（评审把「酸/毒」的**名字**对调；六个颜色都分开了）。
- 结论：六条通道的**可分性**成立；「酸=绿 / 毒=紫」不是跨人群自明约定，**但可教**——
  第三轮图例匹配测试（给图例后把 6 个流源对上名字）**6/6 全对**，所以 tooltip/图鉴即可解决，
  或按 `BLIND-RESULT.md` 的 A/B/C 选项对调色相。
- 设计过程中的盲测（B / W2 / W4）历史记录见 git 提交 `459051e` 及更早：
  B 与 W2 的方向都是 0/4（整体 180° 反读），W4 修正后 4/4；状态从 0/5 修到 5/5。
- 色板对比度/色盲可分性：`CHANNELS.md` + `../../tools/flow-visual/qa.py contrast`。
