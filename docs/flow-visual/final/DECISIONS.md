# 流源视觉 — 决策记录（ADR）

> 每条记录：背景 → 决策 → 替代方案 → 后果。只记录**不可逆或跨通道**的选择；
> 参数级微调不在这里（在 `SPEC.md`）。

## ADR-01：主方向选「流体液滴」，不选「实体小机件」

- 状态：Accepted（第一轮 3 个概念对抗后）
- 背景：三个方向——A 实体（会走路的瓶机）、B 流体（表面张力液滴）、C 符号（符文/电路节点）。
- 决策：以 B 为骨架。
- 理由：
  1. 流源的核心语义是"在流"，B 的头重尾轻剪影**静止时就带方向与运动感**；A 的方块没有这个信息。
  2. B 的"单连通闭合边"直接解决历史死穴「少 ≠ 散」：含量只改半径，永不把一团打散。
  3. B 的通道分层（色相+内纹 / 边缘带 / 包围盒 / 体外残滴 / 拓扑 / 旋转）像素集合互不重叠，
     比 A 的"每个属性一个零件"更省面积，也更容易在 16px 内共存。
- 替代方案：A（实体）保留为"实体感/物品感"的参考；C 因第二轮未交付且更像 UI，弃用。
- 后果：需要在 16×16 内解决"液体形态如何被程序化画出来"，且必须给 Image 回退留路径。

## ADR-02：含量用「体积」，不用「内部密度/亮度」

- 状态：Accepted
- 背景：16px 下"密度"只能靠挖洞或改透明度。
- 决策：四档包围盒（12×8 / 8×8 / 6×6 / 空 6×1），面积 6/28/48/68（档差 +42% 起）；高光固定 2px，小滴因此更亮。
- 理由：挖洞会被读成"漏了/散了"；透明度与"少"没有物理类比。
- 后果：含量占用"尺寸"通道；温度、射程、状态都不能再改包围盒。

## ADR-03：温度只改「边缘带 + 表面附着力」，不改尺寸

- 状态：Accepted
- 背景：历史上温度被两次做成"宽度"（外宽、芯宽）都被否决。
- 决策：冷 = 冷色描边 + 霜点；热 = 暖色描边 + 蒸汽孔 + 1px 缺口；三档面积/包围盒逐像素相同。
- 理由：静态可读、与含量（尺寸）正交、与成分（体色/内纹）分层。
- 替代方案：温度用 4×4 符号（channels.md 推荐）——更稳但更像 UI 图标，与"液体"语言冲突，弃用。
- 后果：描边颜色变成温度的第二信号，必须保证描边**不承担成分**；成分只走体色与内纹。

## ADR-04：射程不用「尾长」，用「离体标记 / 尾段」

- 状态：Proposed（待第二轮评审裁决）
- 背景：尾长同时被速度（拖尾）与含量（体积）语义占用。
- 候选：
  - B 原案：尾部外侧 1–2 个暗淡残滴（数量 = 剩余射程）。
  - W1：尾脊分 3 段，亮段数 = 射程。
  - W2：头部 1px 弧环分 3 段。
- 决策：评审后从三者中选一；判据是"与含量同时变化不产生歧义"且"语义是还能走多远，不是快坏了"。
- 后果：若都不成立，退回"射程不常驻显示，只在悬停/选中时显示"。

## ADR-05：不引入自定义 shader；纯顶点优先，图集可选

- 状态：Accepted
- 背景：IL2CPP 下 `Shader.Find` 不可靠，UI/Default 是唯一稳定材质。
- 决策：
  1. 主路径 = 一个 `MaskableGraphic` 画完整层，1 次重建 / 1 draw call；
  2. 回退 = 每源 2–4 个 `Image` + 一张 ≤64×64 图集；
  3. 不依赖 Bloom、加色、柔边；半透明叠加 ≤2 层。
- 替代方案：AssetBundle + 自定义 shader（被否：版本脆弱、体积大、违反 C6）。
- 后果：视觉上不能做真正的"发光"，只能靠分层与高对比剪影。

## ADR-06：数据契约分主轨 / Tier-0

- 状态：Accepted
- 背景：逻辑层今天只有 Moisture/Temperature/Direction/Speed。
- 决策：设计按完整契约（Composition/RangeRemaining/State）写；同时给 Tier-0 降级映射，
  且 Tier-0 **不得占用**将来主轨要用的像素位置。
- 后果：需要用户批准一个独立的逻辑层只读字段任务；在此之前只能上 Tier-0 视觉效果。

## ADR-07：旧粒子实现整份作废

- 状态：Accepted（用户明确）
- 背景：粒子场 v2（1024 上限、840 quads/源、顶点绘制）未达预期且预算超标。
- 决策：不继承其参数、结构、文件名；新设计独立于 `src/Presentation/Particles/**`。
- 后果：旧文件暂不删除（删除需单独授权），但不再被任何设计引用。
