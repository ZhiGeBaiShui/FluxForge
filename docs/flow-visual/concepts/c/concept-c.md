## 0. 一句话概念

**流源不是一团光，而是一枚被装进 1 格的「活的仪表」：中心是材料本身的符号，外面三圈是它的容量、余程和状态。**

它在世界里的身份是「机器上的电路节点」，不是 HUD 控件；所有信息用仪表的读法（环=容量、针=余程、刻度=标尺、火花=在流），因此它属于背包里的机械，而不属于屏幕上的 UI。

### 三条设计原则

**P1 一属性 = 一个可数的物理量。**
6 条信息各自绑死在**不同种类**的量上：形状 / 段数 / 点位 / 角度 / 数量 / 朝向。
没有两条信息共用同一个量，也没有一条信息只靠"感觉"。逐条见 §3。

**P2 读法是仪表，不是图标。**
容量做成环上的 2px 灯段（像电池电量环），余程做成 14×14 刻度环上的一枚针（像油表），
状态做成轨道上的火花（像示波器上的一个脉冲点）。**图标是"贴上去的"，仪表是"长在上面的"**：所有编码都沿径向分圈、沿周向分位，没有一条是"居中放个 icon"。

**P3 亮度与相位只负责"活"，永不承载信息。**
呼吸、脉冲、亮冠、拖尾全部作用在**不编码任何属性**的变量上（亮度/相位/尾迹）。
因此"活"可以随便加，不会撞 C2；反过来，任何信息都不许用闪烁表达（C4 静态可读）。

### 三个关键决策（编号，供实现引用）

- **D0 同心轴取 pixel-center (7,7)，即几何中心 7.5。**
  核心 5×5 @5..9、环 9×9 @3..11、状态带 11×11 @2..12 都以 7.5 为心，三层严格同心。
  刻度环取 14×14 @1..14（中心 8.0），与图标 12×12（中心 8.0）对齐——**牺牲 0.5px 的同心，换取刻度不压图标边缘**。
  4x 下这 0.5px 可见（1 逻辑像素），但刻度是 8 枚离散点而不是连续圆环，读数不受影响。
  若实现方要求绝对同心：把刻度环改成 13×13 @1..13 即可回到 7.5，代价是最外圈刻度会盖住 12×12 图标的边缘 1px。
- **D1 核心字形随方向做 90° 整数旋转**，不缩放、不镜像、不抗锯齿；旋转在**数据层**完成（4 套预生成图案），不产生任何 transform。
- **D2 流口（mouth）**：核心前侧边缘中心恒留 1px 空。它既是"喷嘴"的物理形状，也是方向的第一重线索。
- **D3 16×16 内共 4 圈 + 中心**：核心(5×5) / 环(9×9) / 状态带(11×11) / 刻度(14×14)。**不再增加第 5 圈**，否则 1x 必糊。

补充规则：

- **亮冠**只作用在"已经点亮"的环段上（+20% 亮度），**永不点亮新段** → 看动效不会误读含量。
- 火花每 0.1s 走 4px；60fps 下约 0.67px/帧，量化后为每 1–2 帧 1px，**匀速、不抖**（禁止变速抖动，C10）。
- 火花颜色 `#EAF6FF` 近白 + 拖尾 `#6E7F94` alpha 170；拖尾只 1px，不拉长成尾迹（避免与 I3/I4 抢"长度"）。

### 受阻时间轴（同一 1.0s）

| t | 画面 |
|---|---|
| 0.00–0.04 | 前方 3px 墙闪入（alpha 0.4→1.0），喷口由 3px 截断为 1px |
| 0.04–0.12 | 火花在最后位置淡出；前侧两段环内缩 1px；环亮度 100%→62% |

### 状态切换

- 方向切换（L 型拐弯）：喷口 0.06s 淡出→新方向 0.06s 淡入，避免"错台"；字形在同帧完成 90° 替换（预生成图案，不插值）。
- 射程针：0.15s 缓动到新八分位；到位后静止。
- 被收集：火花 3 帧内缩进核心 → 环段自前向后 0.3s 熄灭 → 只留 34% 暗环 + 72% 核心。

## 5. quads 预算（逐部件数出来）

以"UGUI 顶点矩形"为单位，核心字形按**行扫描 run** 计（同色同行的连续像素合并为 1 quad）：

| 部件 | 最坏 | 常态 | 说明 |
|---|---|---|---|
| 核心字形 | 11 | 6–10 | 毒（11 px 各自成段）最坏；油/血/酸 5 run，能量 6 run，水 10 run |
| 流口 | 0 | 0 | 只在字形图案里挖掉 1px，不额外画 |
| 喷口 | 1 | 1 | 3px 连成一直线 = 1 quad |
| 环 | 8 | 8 | 8 段 ×2px，各自独立 |
| 温度点 | 2 | 0–2 | 1px/点 |
| 刻度（含针） | 8 | 8 | 8 枚 1px；针只是换色，不加 quad |
| 火花 | 4 | 1–2 | 汇聚 4 / 分流 2 / 流动 1 |
| 拖尾 | 1 | 1 | |
| 墙 | 1 | 0/1 | 3px 连续 = 1 quad |
| **合计** | **≤34** | **≈32** | 达标（C7 ≤64；rubric 的 ≤32 档只差最坏的毒/汇聚组合 2 枚） |

- **静态 22–30 quads**（核心+环+温度+刻度+喷口），每帧只改火花 1–5 个 quad 的位置/颜色。
- 稳态 0 GC alloc：一次 `SetVerticesDirty` 写预分配的 `UIVertex[34*4]`，不 new 材质、不改贴图。
- 若 16 个流源同屏：≈544 quads ≈ 9 个 batch（默认 UI 材质 + 同图集），可接受；极端情况可把环+刻度+温度合并成 1 张程序化 16×16 贴图（1 quad），总降到 ≈10 quads/个。

## 6. 实现要点（给写 UGUI 顶点层的工程师）

1. **坐标**：16×16 像素网格；`x` 向右、`y` 向上与 UGUI 一致时，把本文的 `y` 翻成 `15-y`（或直接以左上为原点用 `rect.yMax - (py+1)` 换算）。
2. **所有 quad 轴对齐、整数像素**，无旋转 quad、无缩放、无抗锯齿；字形旋转只换图案数据（D1）。
3. **颜色**：核心 = 成分色 × 呼吸系数（0.90..1.00）；环段 = 温度色；暗槽 = `#2B3441`；刻度 = `#4A5568` alpha 150；针 = `#F0F6FF`；火花 = `#EAF6FF`；拖尾 = `#6E7F94` alpha 170；墙 = `#F4F8FF`。
4. **alpha**：所有可见像素 alpha ≥ 128；不存在 alpha < 1e-5 的边缘（点击命中阈值 1e-5，C1）。
5. **状态机**：`flow/blocked/split/merge/collected` 五态 + 方向四态，共 20 组静态顶点模板，切换只做模板替换 + 0.06–0.15s 颜色过渡，不逐帧重建。
6. **禁止**：整块半透明底板、外发光贴图、shader、按帧 new 材质（C6/C7）。

## 7. 风险与失败模式

**R1（最高）"像 UI 图标，不像世界里的东西"。**
本方向天然危险：同心圆 + 刻度 + 亮针，离"选框/准星"只有一步。
缓解：① 环在四正向开 3px 门，永不闭合；② 刻度只 8 枚、压到 alpha 150；③ 喷口和火花一只朝外、一只绕着跑，制造"机器在对外做功"；④ 核心字形用材料色，环用温度色，形成"实体 + 环境光"的两层，而不是 UI 的"描边 + 填充"。
**判据**：给 5 个非项目成员看 1x 静帧 3 秒，问"这是什么"，出现"按钮/图标/UI"超过 2 人即失败，需回到"破环 + 去刻度"的减法版。

**R2 1px 火花在 1x 下的可见性。**
40px 轨道上的 1px 亮点，在真实游戏里可能被读成坏点/噪点，尤其背景是浅色图标时。
缓解：拖尾 2px、火花纯白、轨道固定 11×11（不贴图标边缘）。**这是本方案最脆的一条**，必须在真机 1x 静态截图里验证"能看见一个在跑的点"，否则退化为"火花 2px + 4 个固定位"。

**R3 形状族的 1x 可分性（自评最弱）。**
毒（虚环+孢点）与能量（六边芯片）在去色后都是"环形/块状"，5×5 里只差中心 1px 与边缘密度；1x 下主要靠色相（紫 vs 青）。
这**违反了"形状必须能独立辨识"的精神**（字母达标、精神未达标）。补救路线见 §8 末尾。

**R4 含量（段数）与受阻（内缩）抢同一个环。**
两者用的是不同量（段数 vs 位置偏移），但都在 9×9 环上。若玩家把"内缩"读成"少了一段"，I3 就串台。
缓解：内缩只发生在前侧 2 段、且同时出现 3px 墙与变暗；**内缩 1px 但段仍是 2px 长**（长度不变，只有位置变），可测。若真机测试仍误读，退化为"受阻只做墙 + 变暗，不做内缩"。

**R5 温度用环染色，可能被读成"成分变了"。**
缓解：环色只做低饱和染色（S<45%），成分色永远是核心那一块的高饱和色；且温度另有"角点"这条位置通道兜底。真机测：同一成分在 −20/20/100 三档，玩家是否仍说"这还是水"。

**R6 8 枚刻度 = 一圈虚点，可能像"选择框"。**
当前已压暗；若仍像框，可减到 4 枚（N/E/S/W）并把射程档位降到 4 档（仍满足"至少 3 档"）。

**R7 性能**：34 quads/源、16 源 ≈ 544 quads 可行；但若同屏 64 源（极端背包）会到 2176 quads，需要合并静态层为 1 张程序化贴图（见 §5 末）。

**R8 L 型拐弯**：喷口在拐角处会短暂"贴"到相邻格的符文上（两格相接的边只有 1px 间隔）。
缓解：喷口最长到径 5（y=2），与邻格符文的最小间距 1px；拐弯时 0.06s 交叉淡变，不会出现"两个喷口同时亮"的错位感。

**R9 与粒子层并存**：本方案不依赖粒子；若同屏还有旧粒子尾迹，会稀释"仪表"读法。建议流源本身不再叠粒子，只在被收集时放一次 3 帧火花。

**R10 酸的 Z 字形旋转后会变成 N / S 形，4 向不再"同族"。**
`rotation.png` 第 2 行可以直接看到：酸的上/右/下/左分别是 Z、N 形、S 形、镜像 Z。
其余五族在 90° 旋转下仍是本族（水/毒/油/血/能量均为四重对称，只有流口移动），**只有酸这一族与 I6 打架**。
缓解（三选一）：① 把酸改成四重对称的"锯齿斜纹"（`#...# / .#.#. / ..#.. / .#.#. / #...#` 的变体）；② 给 Z 加一条横贯的 5px 基线与 3px 的固定"腐蚀缺口"，让旋转后仍读成"带缺口的横条"；③ 保留 Z，但酸只走 0°/180°（牺牲上下左右的一致）。**建议先用 ②**，代价是酸的形状族要多 2px 的固定元素。

## 8. 回答 BRIEF §8 的六个开放问题

1. **实体还是流体？** 实体：一枚有固定轮廓的符文/仪表。理由是 4 向 + 受阻 + 分流都要**稳定轮廓**才读得出；流体形态会让"段数/角度"这类可数量失效。
2. **要不要方向性头部？** 要，但不是"头"，是**喷口 + 流口**：3px 指针在环外、1px 缺口在字形上，两者共线，4 向复用同一套图案旋转，不错位。
3. **含量用体积还是密度？** 用**段数（离散体积）**。密度/亮度会和"活"的呼吸、受阻的变暗抢通道；段数是离散的，1x 可数，且天然读成"少"而不是"散"。
4. **射程用哪条通道？** 用**最外圈 14×14 刻度环上的针角度**（8 档）。它与含量（9×9 环段数）不同圈、不同量；与尾迹长度无关（本方案没有尾迹长度这个量）。
5. **6 种成分要不要颜色之外的形状？** 必须给。已给 6 个形状族；但坦白说毒/能量在 5×5 内仍偏接近，见 R3。补救方案：把毒改成"三叶/孢子"（三个 1px 点 + 短弧），把能量保持"实心六边芯片"，两者质量差从 1px 拉大到 9px。
6. **停留/受阻怎么表达"不动了"？** 受阻：火花消失 + 3px 墙 + 喷口截断 + 环内缩 1px + 亮度 62%；停留（静止但仍在流）：火花**减速到 0.25 圈/秒**并停在门外 2px，不出现墙、不变暗。两者靠"有没有墙"区分。

## 10. 自评

- 通道正交：**强**（形状/段数/点位/角度/火花数/朝向，六量互不重叠）。
- 1x 可读性：**中**（形状与色相双通道；但 1px 火花和 1px 温度点偏小，是最大隐患）。
- 静态温度：**强**（位置 + 数量 + 环染，三重冗余，零动画）。
- 像"世界里的东西"：**中偏弱**——这是本方向的原生风险，靠"破环 + 8 枚刻度 + 火花"压住，但没有把握说已经压死。
- **我自己认为最不成立的一条**：**R3，"形状独立辨识"在毒/能量这一对上只是字母达标**。5×5 里"虚环+孢点"与"实心六边形芯片"的差异主要来自填充密度和 1px 中心点，1x 下很可能退化成"一块偏紫、一块偏青"。如果只能用一条来换，我会把毒改成三叶孢形（3 个 1px 点 + 一段 2px 弧），用 9px 的质量差换取真正的形状可分——但那会让"缺口环"这一族的隐喻弱一点。这一点需要在 1x 真机截图里定生死。
