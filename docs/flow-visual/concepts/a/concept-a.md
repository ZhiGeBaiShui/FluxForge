# 概念 A — 实体化：「囊行者」（Vial Walker）

> 一句话：**流源是一枚会走路的小瓶机**——玻璃腔装料、金属盖和两只脚、一个会转向的喷口、身后三颗余烬。
> 它始终是"一个东西"，不是一团雾；所有属性都写在它的**零件**上，而不是写成一束光。

生成脚本：[render_a.py](render_a.py)　全部图形由脚本逐像素生成，未使用任何现有贴图。
图见同目录 `a-*.png`（4x 均为 NEAREST 放大；1x 为原始像素）。

---

## 1. 三条设计原则

1. **剪影优先于内部**：8×8 的方形主体 + 2px 喷口凸起 + 2px 金属盖 + 两只金属脚，外圈永远有 1px `#0B0F18` 描边；去掉颜色后仍能认出"一个带喷嘴的罐子"。
2. **一属性一零件，零件互不重叠**：玻璃腔 = 成分 + 含量；盖/脚/侧壁 = 温度；喷口 + 余烬 = 方向；余烬亮格数 = 射程；格角标 = 状态。**同一个像素永远只属于一个通道**（见 §3 分区）。
3. **所有变化都在 1–2 像素步内完成**：含量 1/3/5 行、温度 4 个像素、余烬 1/2/3 颗、状态角标 3×3 字形——没有渐变、没有抗锯齿、没有半透明边缘。

## 2. 逐像素构造（静止态，右向 / 上向）

图例：`#`=描边 `#0B0F18`，`m`=金属 `#A7B3C7`，`o`=主色高光，`+`=主色，`x`=主色阴影，
`:`=空玻璃 `#171E2E`，`e`=余烬 `#FFC24A`，`.`=空。**本图 = 水 / 满 5 行 / 常温 / 流动 / 射程 3**。

### 右向（基准朝向，16×16 格）

```
y0  ................
y1  ................
y2  ................
y3  ................
y4  .....#mmmm#.....   ← 瓶盖：x5..10 描边，x6..9 金属（6px 宽，1px 高）
y5  ....########....   ← 肩线 x4..11
y6  ...e#oo+++x###..   ← 液面纹理行（水：oo+++x）+ 喷口上唇 x12,x13
y7  ....#o++++x#+o..   ← 喷口本体 x12=主色、x13=高光；左/右壁反光与阴影
y8  ...e#o++++x###..   ← 液面下第一行 + 喷口下唇
y9  ....#o++++x#....
y10 ...e#o++++x#....   ← 液柱底行
y11 .....m####m.....   ← 底边 x5..10，两只金属脚 x5 / x10
y12 ................
y13 ................
y14 ................
y15 ................
```

要点（逐像素可核对）：
- **主体 x4..11（8px 宽）× y4..11（8px 高）**，几何中心 (7.5, 7.5) = 格中心，四向恒定。
- 玻璃腔 **x5..10 × y6..10 = 6×5 = 30 格**；左壁内列 x5 恒为 `hi`，右壁内列 x10 恒为 `sh`，中间 4 列 `main` → **2–3 阶明暗，光源左上**。
- 下角切角：y11 只有 x5..10，左右下角各少 1px → 圆润剪影。
- 头：x12..13, y6..8 的 2×3 暗块，中行 x12=`main`、x13=`hi` → 唯一伸出主体的实体凸起。
- 尾：x3 上 y6/y8/y10 三颗 1px 余烬，间隔 1px 透明 → 不是实心条，是**可数**的点。
- 不透明像素合计 **69**（描边 24 + 金属 6 + 液柱 30 + 喷口 6 + 余烬 3）。占 16×16 的 27%，12×12 图标的 48%（C5 留白达标）。

### 上向（由基准旋转得到，非重画）

```

y1  ................
y2  ......#o#.......   ← 原 x13 高光转到 (7,2)
y3  ......#+#.......   ← 原 x12 主色转到 (7,3)
y4  .....#mmmm#.....
y5  ....########....
y6  ....#oo+++x#....
y7  ....#o++++x#....
y8  ....#o++++x#....
y9  ....#o++++x#....
y10 ....#o++++x#....
y11 .....m####m.....
y12 ......e.e.e.....   ← 余烬转到下侧 x6/x8/x10
y13 ................
y14 ................
y15 ................
```

### 4 向如何复用（整数旋转，零重画）

只旋转**喷口**和**余烬**两组像素，绕格中心 (7.5, 7.5)：

| 朝向 | 变换 | 喷口落点 | 余烬落点 |
|---|---|---|---|
| 右 | `(x, y)` | x12..13, y6..8 | x3, y6/8/10 |
| 上 | `(y, 15-x)` | x6..8, y2..3 | x6/8/10, y12 |
| 左 | `(15-x, 15-y)` | x2..3, y7..9 | x12, y6/8/10 |
| 下 | `(15-y, x)` | x7..9, y12..13 | x6/8/10, y3 |

变换在 16×16 格上做**整格旋转**（坐标全为整数，等价于把 16×16 贴图旋转 90°，NEAREST、无插值），所以四向像素完全一致，L 型拐角**不会出现半像素错台**。
主体（方形 8×8，中心即格中心）**不旋转**——它带盖和脚，旋转会让"盖子"跑到侧面，破坏"物品图标"的读法，还会让主体绕格心公转 0.5px。这在 C8 下是更稳的取舍。

## 3. 通道分区（一属性一零件，物理不相交）

| 像素区域 | 坐标（右向） | 像素数 | 归属通道 |
|---|---|---|---|
| 玻璃腔 | x5..10, y6..10 | 30 | **I1 成分** + **I3 含量**（同一区域的两种编码：色相/纹理 vs 行数） |
| 盖 + 脚 + 上部侧壁 | (6,4)(9,4)(4,6)(11,6) / (7,4)(8,4)(5,11)(10,11) | 4+4 | **I2 温度**（只改五金件颜色，一个腔体内的像素都不动） |
| 喷口 | x12..13, y6..8 | 6 | **I6 方向** |
| 余烬点 | x3, y6/8/10 | 3 | **I4 射程**（亮几颗） |
| 格角标 | x0..4, y0..4 | 25+字形 | **I5 状态** |
| 描边/金属/玻璃 | 其余 | 24+6+30 | 形体（无编码） |

> 这就是 I2 不抢 I1 的答案：**温度只动瓶盖、脚、上侧壁这 8 个五金像素，成分只动玻璃腔的 30 个像素**，两者像素集合交集为空；红热的盖（`#FF4D3A`）和血色的液（`#C43432`）即使同色系也**不在同一个位置**，不会读混。

## 4. I1–I6 映射表

| # | 通道（零件） | 编码 | 档位 / 数值 |
|---|---|---|---|
| **I1** | 玻璃腔液体的**色相 + 液面纹理（6px 行）** | 主色/高光/阴影 + 顶行 6 格明暗花纹 | 水 `#3E8FE2/#A6DAFF/#1F4F8F`，纹理 `oo+++x`（波浪）；毒 `#7FC63F/#D8FF8A/#3E6E17`，`+o+o+o`（气泡孔）；油 `#C48A2A/#F3D27C/#6B4508`，`+ooo+x`（宽高光斑）；血 `#C43432/#F57C64/#6E1715`，`xx++xx`（暗色结块边）；酸 `#CBDF3C/#F7FF9E/#6F7E12`，`o+xo+x`（锯齿缺口）；能量 `#D06BFF/#F2D9FF/#5A2A96`，`+xox++`（电芯夹暗边）。每件 **3 自有色 + 3 系统色 = 6 色** |
| **I2** | 瓶盖/脚/上侧壁的**静态覆层**（4px，恒定位置、恒定数量） | 冷=霜点 `#DFF6FF`；常温=无；热=热斑 `#FF4D3A` | 冷：(6,4)(9,4)(4,6)(11,6)；热：(7,4)(8,4)(5,11)(10,11)。**不靠动画、不改尺寸**，静态帧可判 |
| **I3** | 玻璃腔内**液柱行数**（自底向上） | 0 / 1 / 3 / 5 行（满=5 行占满 y6..10） | 少=1 行（1×6 实心条，"短而实"），中=3 行，满=5 行；行距 2 行，边界是 1px 明暗。**外形尺寸 0 变化**：C3 允许 ≤3 档，这里直接取 1 档（恒定），不做宽度编码 |
| **I4** | 尾部**余烬亮格数**（3 个固定槽位） | 亮 3/2/1/0 颗 | 槽位 (3,6)(3,8)(3,10) 恒定；亮= `#FFC24A`，灭= `#7A3A10`。与含量区分：含量在**腔内成行**，余烬在**腔外成点**；与速度无关（速度不改余烬） |
| **I5** | 格左上角 5×5 **角标**（暗底 + 3×3 字形） | 流动=无角标；受阻=`X`(5px)；分流=`Y`(4px)；汇聚=`倒Y`(4px)；被收集=`✓`(4px) | 底板 `#060911` 25px，字形 `#EAF2FF`；位置 x0..4,y0..4 固定，静态可读；与 I4 余烬、I1 液体零交集 |
| **I6** | **喷口 2×3 凸起**（+方向）与**余烬点**（−方向） | 喷口实体凸出 2px、3px 高；余烬在反侧 | 喷口 6px 中 2px 是主色/高光；四向由 §2 的整数旋转得到，4/4 一致 |

色觉可用性（实测，Machado 2009 去氘模拟，RGB 欧氏距离）：最接近的一对是 **水 `#3E8FE2` ↔ 能量 `#D06BFF`，距离 40.1**；6 色只聚成约 3 组（水/能量、毒/油/酸、血），**达不到简报要求的 4 组**。亮度（相对亮度）分别为 0.144 / 0.262 / 0.301 / 0.312 / 0.453 / 0.658，可作为第二判别量；形差（液面纹理）在 4x 清楚、1x 只能读到"粗/细/碎"的质地差异。这是本方案最弱的一环，见 §6。

## 5. 运动时间轴（60fps，0.0–1.0s = 帧 0–59，无缝循环）

| 帧 | 变化（只改这一项） |
|---|---|
| f00 | 基准帧：y=0，液面 slosh=0，余烬 3 亮，喷口 `main` |
| f01–f09 | 待机：y=0；余烬第 1 颗在 f01/f05 与 `#7A3A10` 互换 1 帧（只闪，不改亮格数）；其余不动 |
| f10 | **上跳 1px**：整体 y=-1（只改 RectTransform，不重建顶点） |
| f11 | 液面滞后：slosh=+1（液面纹理行右移 1px，液柱行数不变） |
| f13 | slosh 回 0 |
| f14–f17 | **发射瞬间**：喷口高光 `hi`↔`main` 交替 2 次（f14 亮 / f15 暗 / f16 亮 / f17 暗）；f15 在喷口外侧 (14,7) 生成 1 颗 1px 火花，f16 移到 (15,7)，f17 消失 |
| f18–f19 | y 回 0（落回格位，整数像素，不跨格） |
| f20 | 呼吸第二周期开始，重复 f00 的位移相位 |
| f22 | 液面 slosh=-1（反向），f24 回 0 |
| f30 | 第三周期 y=-1 |
| f32 | 受阻时进入另一套：**不再上跳**，改为 x 方向 ±1 抖动，周期 4 帧：f32 x=0，f33 x=+1，f34 x=0，f35 x=-1；同时角标 `X` 每 8 帧明暗互换（f32 亮，f40 暗） |
| f36–f39 | 液面 slosh=+1（被顶住时液体向前涌 1px） |
| f40–f43 | 余烬衰减演示：3 亮→2 亮（只灭最外 1 颗，槽位不动） |
| f44–f49 | 回到 3 亮 |
| f50–f59 | 收尾：y=0、slosh=0、喷口 `main`，与 f00 完全一致 → 循环 |

约束：所有位移是**整格像素**；上跳只有 1px；抖动只有 ±1px 且周期 4 帧（16ms 帧间隔），不会读成掉帧；液面只做水平 1px 错位，不改液柱高度（I3 不动）；角标只做明暗，不改字形（I5 不动）。

## 6. quads 预算（逐部件）

| 部件 | quads | 顶点 | 内容 | 每帧是否重建 |
|---|---|---|---|---|
| 本体（描边+金属+玻璃+脚） | 1 | 4 | 13×10 贴图区，静态 | 否 |
| 液柱（含液面纹理） | 1 | 4 | 6×5 贴图区，按档位裁 UV 顶部 N 行 | 仅换档时 |
| 喷口 | 1 | 4 | 2×3 贴图区 | 仅转向/发射时 |
| 余烬 | 1 | 4 | 1×3 贴图区，亮格数由 UV/顶点色切换 | 仅换档/闪帧时 |
| 温度覆层 | 1 | 4 | 固定 4 像素（冷/热各一张） | 仅换温时 |
| 状态角标 | 1 | 4 | 5×5 底板 + 3×3 字形 | 仅换状态时 |
| **合计** | **6** | **24** | 单张 atlas，1 次 draw call | 稳态 0 次；0 GC alloc（复用 VertexHelper 缓冲） |

对比预算上限 64 quads：**6/64**。动画位移走 Transform（不重建网格）；只有含量/射程/状态/方向变化时才重建 24 个顶点。若把 6 个部件烘成 1 张按状态切好的 16×16 图集，可退化为 **1 quad / 4 顶点**，代价是图集组合数（方向 4 × 温度 3 × 含量 4 × 射程 4 × 状态 5 × 成分 6）过大，不推荐。

## 7. 风险与失败模式

| 风险 | 表现 | 缓解 |
|---|---|---|
| **1x 下形差太弱** | 液面 6px 纹理在 1x 只剩"质地"，色盲玩家靠形分不出毒/油 | 优先级最高的待改项：把 6 色重排（实测 `毒 #53E04A / 酸 #E6EE6E / 血 #A81F26 / 能量 #F04FC0` 可把去氘最小距离从 40 提到 64.8），再补 1px 专属记号 |
| 温度只 4px | 1x 下冷/常温差异弱于"有没有角标" | 冷/热的覆层放在**不同零件**（冷=盖+上壁，热=盖心+脚），位置差 ≥ 5px；可再加 1px 冷色描边替换（但会动剪影，暂不做） |
| 余烬"点数"读成"粒子散开" | 3 点被当成特效 | 槽位固定、间隔 1px、成列，且**数量只减不随机**；被收集时全部熄灭 |
| 角标遮挡图标 | 5×5 暗块压住 12×12 图标左上角 | 只在上半格，最大遮挡 25/144=17%，且仅在非流动状态出现 |
| 液柱满格时遮图标 | 30px 不透明液体盖住图标 | 液体只在腔体内，腔体外 1px 描边让图标边缘透出；上跳 1px 让图标上下边周期性露出 |
| 主体不旋转 | 上/下向时"脚"仍在下方，像 3/4 视角 | 这是刻意的：主体=机箱，喷口=炮塔；配合 1px 上跳读作"行走"，比整只旋转更像物品 |
| 喷口 2×3 被读成"镜头/摄像头" | 像相机不像喷嘴 | 喷口只有 1px 彩色芯，且与余烬同轴；发射帧的火花会明确它是"出口" |
