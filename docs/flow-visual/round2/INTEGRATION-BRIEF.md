## 0. 定位

**主形态用 B**（12×8 液滴、1px `#241E2E` 闭合张力边、体内 alpha 208、3 阶明暗、头重尾轻）。
**方向与状态用 W4**（删针尖、前端 6px 平口 + 前脸 2px 高光 + 2×2 亮核偏前；5 个物理直喻状态）。
**射程用底部 3 个 1px 点**（新方案，见 §3）。**动效用 W3**（12 帧 + 两条时间基）。

**不要再引入 W2 的头部弧环**：它会与方向线索抢注意力，而且"光环比液滴长"在小含量档已证明是负担。

## 1. 不可变的部分（B 已盲测通过，别动）

- 温度通道：3/3 盲测正确 → 保留"边缘带颜色 + 霜点 / 蒸汽孔 + 缺口"，三档包围盒逐像素相同。
- 含量通道：4/4 盲测正确 → 保留 4 档包围盒（空 6×1 / 少 6×6 / 中 8×6 / 多 10×8），高光恒 2px。
- 体 alpha 208、边长 1px、3 阶明暗、闭合边。

## 2. 方向（W4）

- 前端：x=13 连续 6px 平口（钝），**没有 1px 尖角**；
- 前脸：2px 高光，`mix(成分色,#FFF,0.85)`；
- 核：2×2 亮核，色 `mix(成分色,#FFF,0.80)`，位于核中心距前端 2px；
- 后端：2px 窄平口，`mix(成分色,#241E2E,0.7)`，alpha 130；
- 四向：同一 role 表绕格心整数旋转；bbox 中心恒 (7.5,7.5)。

## 3. 射程（新方案，必须在 1x 下可数）

- 位置：格的底部，`y=14`，`x=4 / 6 / 8` 三个 1px 点（间隔 1px 空）。
- 亮 = `mix(成分色,#FFF,0.75)` alpha 255；灭 = `mix(成分色,#1B1715,0.75)` alpha 200。
- 档位：射程 3/2/1 格 → 亮 3/2/1 个；从**左**往右灭。
- 为什么在底部：图标 12×12 在 y=2..13，y=14 不压图标；不占尾部（速度/状态）也不占头部（方向）。
- 与含量正交：点固定在外框，不随包围盒变化；与温度正交：点无霜/孔。

## 4. 状态（W4 的物理直喻）

| 状态 | 静态签名 | 与 flow 的差量 |
|---|---|---|
| flow | 无附加物 | 0 |
| blocked | 前方 `1×3` 中性墙 `#C9C2B8`（贴在前端外 1px）+ 轴向压 1px + 尾部回卷 1px，撤掉前脸高光 | 墙 3px + 压缩 |
| split | 两瓣沿运动轴分离 **2 整行背景**，各 33px、各带 1px 闭合边、各自有头 | 中间 24 空 px |
| merge | 两臂 29+29 合成 58px，**后缘** 6px V 缺口 + 撞击点 1px 亮缝 `mix(色,#FFF,0.6)` | V 6px + 缝 1px |
| collect | 前端开口 + **连续** 1px 流（与皮肤四邻接）伸 2px + 2px 喇叭口 | 流 2px + 口 |

**判据**：5 张静态帧给没看过设计的人，≥4 种能对上；split/merge 不得互换（一个中间是空、一个是亮缝）。

## 5. 动效（W3）

- 包络锁 12 帧 / 1.0s（尾长 2→4→2、高光扫过、回卷）。
- 呼吸走浮点相位：`φ += 2π·2·k·dt`，k = 0.7 / 1.0 / 1.4（冷/常温/热）；只动第 4 行与第 11 行 ±1px，面积守恒。
- 受阻：预压 2 帧 → 撞击 1 帧内收 2px → 3 帧回弹（含 1px 过冲）→ 2 次微抖 → 静止（逐帧 diff=0）。
- 进入新格：2 帧 1px 边框，alpha 0.35 → 0.17 → 0。
- 禁止：3 帧以上静止、纯白闪、超过 2px 的单帧位移。
