# 第二轮评审规则（review panel 用）

> 评审对象：`round2/w1/`（B-solid）、`round2/w2/`（B-core）、`round2/w3/`（动效）。
> 评审只看**证据**，不投票；每条结论必须给图/坐标/数字/文件行号。
> 评审是只读的：不许改设计稿，不许替写手重画。

## 1. 评分表（每项 0–2，任何 0 分即淘汰）

| # | 项 | 0 分 | 1 分 | 2 分 | 证据形式 |
|---|---|---|---|---|---|
| 1 | 1x 可读性 | 认不出是流源 | 能认出但要猜 | 一眼是"流动的东西" | 16×16 原图 + 4× 对照 |
| 2 | 温度静态可读 | 只能靠颜色/动画 | 并排能比出来 | 单帧可判冷/常温/热 | 3 张 1x 并列，盲判记录 |

## 2. 盲判协议（perception test）

1. 从 `tiles/manifest.json` 生成**不标注**的接触表（`qa.py blind`），评审只看到编号。
2. 评审按编号写出判断（成分 / 温度 / 含量 / 射程 / 状态 / 方向）。
3. 与 `key.json` 对比，统计每项准确率；低于 80% 的属性视为**该通道失败**。
4. 至少跑两组：正常视觉 + deutan 模拟。
5. 盲判时禁止看 `spec.md`、禁止看文件名。

## 3. 对抗评审必答的 8 个问题

1. 这套东西**静止时**还像"在流"吗？如果不像，方向通道是不是全靠头部？
2. 温度三档去掉颜色后，还能靠**形状**分开吗？给灰度图证据。
3. 含量从"多"掉到"少"时，玩家会不会读成"漏了/坏了"？
4. 射程的编码在**语义**上成立吗？（"还能走多远" vs "快坏了"）
5. 分流/汇聚的静态签名，在 1x 下和"压扁/缺口"能区分吗？
6. 12 帧里有没有任何一帧会让包围盒面积变化 >2px²？（那会被读成含量变化）
7. 半透明本体叠在**浅色**图标上会不会消失？给浅底遮挡图。
8. 如果只允许保留一个属性通道，砍哪个损失最小？为什么？

## 4. 结论格式

```
VERDICT: w1 | w2 | merge | reject-both
REASONS: 3 条以内，每条带证据
MUST-FIX: S0/S1 列表（每条：问题、证据、最小修法）
KEEP: 必须保留的 2–3 个装置
KILL: 必须删除的 1–2 个装置
OPEN: 需要用户拍板的问题（≤3）
```
