# 流源视觉通道分配研究（信息设计）

> 输入：`docs/flow-visual/BRIEF.md` v1（§3 I1–I6、§4 C1–C10、§5 否决清单）。
> 数值脚本：`docs/flow-visual/research/contrast.py`（Python 3.12 / Pillow 12.3），对照图：`docs/flow-visual/research/contrast.png`（8x NEAREST + 1x 实际像素行）。
> 本文只做**信息→通道**的分配与可分性证明，不改逻辑层、不用 shader，也不写 `src/**` 与 `assets/**`。
> **双轨前提**（director 2026-10-20 裁决）：逻辑层当前只有 `Moisture` + `Temperature`，无成分 6 分量、无剩余射程、无状态字段。因此 §5 同时给「完整轨」与「Tier-0 降级轨」。

## 0. 结论先行

- **16px 网格里 6 条信息无法各占一条独立通道**：几何账是 256 px²/格、图标占 144 px²、只剩 112 px² 边缘；除中心 6×6 体之外，任何新通道只能落在 1–2 px 宽的边缘带。三套方案里没有一套做到 6 条全独立，只能做到「4 条硬独立 + 2 条空间分时」。
- **色相单独只能撑 4 组**：6 个朴素语义色在「deutan/protan 任一塌缩即归组」的取严判定下 = **4 组**（deutan 4 组、protan 5 组）；`毒-油` 在 deutan 下 ΔE=4.9、亮度差 ΔL*=0.7，属**完全塌缩**，必须靠亮度带或形状兜底。
- **血红在 protan 下等于消失**：`#D0342C` → 模拟 `#201A06`，L* 从 47.0 掉到 9.5，Y=0.011，对 `#332B28` 对比仅 **1.19:1**。红色相在暗底上无解（把红提亮到 `#E8605A` 仍只有 1.08:1），只能靠**常量 1px 轮廓** `#E8E0D8`（10.60:1，protan 模拟后 7.46:1）保住"物体存在"，颜色识别降级。
- **推荐方案 = A 的通道骨架 + 推荐色 + 常量轮廓 + 4×4 温度符号**；6 条信息的通道为：色相（I1）、符号（I2）、面积/体积（I3）、数量（I4）、边框（I5）、位置（I6），**0 个同通道复用**，静态帧可读，≤20 quads。
- **Tier-0 只点亮 4 条通道**（色相+饱和度 / 符号 / 体积 / 位置），把**数量、边框、纹理、时序、明度带、5 个非水色相**整条空出来，未来加字段不需要重排映射。

## 1. 通道清单（11 条）

度量口径：格 16×16 px；物品图标 12×12 居中（x=2..13, y=2..13）；边缘带宽 2 px；1x 下"可读"定义为**单帧扫视 ≤200 ms、无提示、6 选 1 命中率 ≥90%** 所需的物理差。所有"档数"均为**保守可辨档数**，不是理论编码位。

| # | 通道 | 可承载档数 | 16px 下的分辨率上限（数字） | 典型误读 | 判定 |
|---|---|---|---|---|---|
| 1 | 色相 | 6（正常视觉）；CVD 2 轴 → 最多 4–5 组 | 相邻色相 ≥30°（L*<70）/ ≥45°（L*>80）；实测 6 色最小正常 ΔE76=34.2（毒-酸）。青-蓝 <25°、黄绿-黄 <20° 在 1x 合并 | 青读成蓝；黄绿读成黄；品红读成红；暗红读成黑 | **I1 主通道** |
| 2 | 明度 | 4 档（ΔL*≥12）；1px 面积需 ΔL*≥14 | 暗底 `#332B28` 上要 3:1 需 L*≥49.4；4 档落在 L* 50/62/74/86；再密就退化为"亮/暗"2 档 | 变亮读成"热/充电/满"；暗红读成"空" | I1 冗余 / I2 备选；同屏只能给一个属性 |
| 3 | 尺寸 | 3–4 档（线性差 ≥2 px） | 卫星标记 2/4/6 px 三档；主体宽度**禁用**（C3）。16px 里 2px=12.5% 格宽，4px 差已是极限 | 大小读成"远近/强弱"；1px 差读成抗锯齿脏边 | 仅卫星标记；不作主体 |
| 4 | 形状 | 4×4→3 种；5×5→5 种；3×3→2 种 | 45° 斜边要 7px 才读得出（BRIEF §5）；4×4 内 X/横杠/三角可区分；圆角与直角差 1px 时读成"渲染毛边" | 形状家族读成"状态"；圆角差读成脏边 | I2 温度符号 / I5 备选 |
| 5 | 数量 | 1–4（subitizing）；5 勉强；≥6 要逐个数 | 1px 点、间距 ≥2px 时，12px 内最多 4 个；2×2 点最多 3 个（间距 3px） | 3 点读成"省略号"；1↔2 点扫视错误率最高 | **I4 射程主通道（推荐）** |
| 6 | 位置 | 4 个正方向锚点；安全槽位 ≤6（4 角+2 边中） | 槽间距 ≥3px 才不并读；16px 内 8 槽（2px 间距）不可靠；L 型拐角处 ±1px 偏移读成"错台"（C8） | 1px 偏移读成对齐 bug；相邻槽位并读 | **I6 方向主通道（推荐）** |
| 7 | 运动 | 2 态（动/停）+ 速度 3 档 | 16px/格；60fps 下 1 格/秒=0.27px/帧可读，>64px/s 出现跳格；**静态帧 0 信息** | 停顿读成卡顿（C10）；慢速读成"受阻" | 只作 I5 的辅助线索，不作唯一依据 |
| 8 | 时序（闪烁节奏） | 3 档（0 / 1.2 / 3.0 Hz） | 每相位 ≥2 帧（60fps → 周期 ≥0.33s）；>3Hz 有光敏风险；1x 下 0.3s 周期与"掉帧"难分 | 闪烁读成警报/受伤；不同步读成渲染 bug | 只作射程/状态备选；**不得进推荐轨** |
| 9 | 边框 | 3 种图案可靠；5 种勉强 | 1px 环周长 60px（16×16）；可切 4 边×2 态，但 1x 实际只读出"完整/有缺口/点线"3 类；历史上"每格 1px 虚线表射程"已被否（§5） | 缺口读成渲染缝；点线读成射程 | **I5 状态主通道（推荐，≤5 图案）** |
| 10 | 符号 | 4×4→3 种；5×5→5 种；≥6 不可靠 | 4×4=16 px²；5×5=25 px²（压图标 25/144=17%）；符号之间需 ≥2px 间距 | 雪花读成星/裂纹；火焰读成箭头；符号读成"物品图标的一部分" | **I2 温度主通道（推荐 4×4）** |
| 11 | 纹理 | 3 种图案（周期 2/3/4 px）；密度 3–4 档 | 4×4 内 25/50/75/100% 覆盖=4/8/12/16 px²；1px 棋盘在移动体上产生摩尔纹/闪烁（C10） | 密度读成"脏/噪点"；"少"读成"散"（§5 已否） | 只作 I2/I4 备选；移动体上禁用 1px 棋盘 |

**通道容量小结**：名义总容量 ≈ 2.6+2+2+2.3+2+2.6+1.6+1.6+2.3+2.6+2 ≈ 23 bit；但 16px 下相互独立的**有效通道只有 5–6 条**（形状/符号/纹理互相干扰，明度/色相在暗底上互相干扰）。这是"6 条信息必须共享 2 条通道"的根因。

## 2. 三套完整分配方案

三套都使用同一套 6 个成分色（正常视觉 6 色可分，最小 ΔE=34.2）与同一条 1px 常量轮廓；差异只在通道分配。下表 I1–I6 → 通道 + 具体编码（像素/帧/hex 全给）。

### 方案 A —— 色相优先 / 体积 / 计数射程（保守、静态最强）

| 信息 | 通道 | 具体编码 |
|---|---|---|
| I1 成分 | 色相 | 水 `#3FA9F5` / 毒 `#57C84D` / 油 `#C9A227` / 血 `#D0342C` / 酸 `#B7E22B` / 能量 `#B25CFF`；体 6×6 填充 |
| I2 温度 | 明度 | 固定 3×3 温度芯（体中心），冷 `#6E8FA8` L*=57.8 / 常温 `#C8C2B8` L*=78.7 / 热 `#FFF1C4` L*=95.2；ΔL*=20.9 / 16.5 |
| I3 含量 | 体积（面积） | 体内 4×4 填充 1/2/4 行 = 4/8/16 px²（3 档 + 空） |
| I4 射程 | 数量 | y=14 行 3 个 1px 刻度（x=1/3/5），1/2/3 个 = 3 档 |
| I5 状态 | 边框 | 1px 环（60 px 周长）5 图案：全实 / 上缺口 / 下缺口 / 左右缺口 / 点线 |
| I6 方向 | 位置 | 3×3 头贴在体 4 侧：上 (7,2) / 下 (7,11) / 左 (2,7) / 右 (11,7)，不旋转 |

- 优点：① 6 属性 6 条不同通道，**同通道复用 = 0**；② 全部静态可读（I2 单帧可判，满足 C4）；③ quads 最少（约 20），预算最稳。
- 风险：① I1 的 6 色明度跨 L*47–84，与 I2 的明度芯**抢"明度"这个感知量**（C2 擦边）；② 5 种 1px 环图案在 1x 下实际只读出 3 类（见 §1 通道 9），`分流/汇聚` 易混；③ 血色 protan 下 L*=9.5、对比 1.19:1，无轮廓时不可见。

### 方案 B —— 形状冗余 / 密度 / 时序射程（色盲最稳、动效最多）

| 信息 | 通道 | 具体编码 |
|---|---|---|
| I1 成分 | 色相 + 形状 | 3 形状族（圆滴/菱形/气泡环）×2 色相 = 6；形状在体 4×4 内，单形 9–16 px² |
| I2 温度 | 符号 | 4×4 符号：(1,1)–(4,4)，雪 X / 横杠 / 火焰三角，12 px² |
| I3 含量 | 密度 | 体 4×4 内 25/50/75/100% 网点覆盖 = 4/8/12/16 px²（4 档） |
| I4 射程 | 时序 | 体亮度呼吸周期 1.2s / 0.55s / 0.30s（3 档）；每相位 ≥2 帧 |
| I5 状态 | 边框 | 同 A（5 图案 / 60 px 环） |
| I6 方向 | 位置 | 同 A（3×3 头 4 向） |

- 优点：① 形状族让 CVD 下仍有 6 组可分（色相失效时靠轮廓）；② 密度只在 16 px² 内变化，**遮图标面积最小**（4×4）；③ 时序不占静态像素，给射程留出全部空间。
- 风险：① **形状通道被 I1/I2/I6 三个属性同时使用**（3 族 + 符号 + 头），直接违反 C2；② 1px 网点在移动体上摩尔纹/闪烁，C10 高风险；③ 射程只在动画里可读，静止帧丢失，与"玩家只扫一眼"冲突。

### 方案 C —— 双形状类 / 计数含量 / 纹理射程（省面积、读数最快）

| 信息 | 通道 | 具体编码 |
|---|---|---|
| I1 成分 | 色相 + 2 形状类 | 液态（圆）/ 晶态（方）2 类 ×3 色；形状只做冗余，不做 6 分类 |
| I2 温度 | 位置 | 左列 3 个 2×2 槽位 (1,3)/(1,7)/(1,11)：下=冷、中=常温、上=热 |
| I3 含量 | 数量 | 底边 2/4/6 个 1×2 刻度（y=14），数刻度即含量 |
| I4 射程 | 纹理 | 6px 尾迹上虚线周期 2/4/6 px（3 档） |
| I5 状态 | 边框 | 同 A（5 图案 / 60 px 环） |
| I6 方向 | 符号 | 3×3 四向箭头（↑↓←→ 各一套，不自绘旋转） |

- 优点：① 温度用**位置**，静态绝对可读，不依赖亮度（最符合 C4）；② 含量用刻度计数，与"空/满"直觉一致，不受 C3 粗细限制；③ 纹理让射程在静止帧也可读。
- 风险：① 左列温度槽与左向头部 (2,7)–(4,9) **重叠 1px**（x=2），必须错位或缩槽；② 6 个刻度超过 subitizing 上限 4，扫视正确率预计掉 15–25%；③ 2px 周期虚线在 1x 下近似实线（低于 16px 分辨率下限），3 档实际只剩 2 档。

### 三套的关键差异（题目要求的三个轴）

| 轴 | A | B | C |
|---|---|---|---|
| 成分是否用形状 | **否**，纯色相 | **是**，3 族×2 色 | **是**，仅 2 类冗余 |
| 含量用体积还是密度 | **体积**（液面高度 1/2/4 行） | **密度**（网点 25–100%） | **数量**（刻度 2/4/6，第三答案） |
| 射程用哪条通道 | **数量**（3 刻度） | **时序**（3 呼吸周期） | **纹理**（3 虚线周期） |

## 3. 色盲与对比度实测

**模拟公式**（`contrast.py` 实现）：sRGB→线性 RGB；`[R'G'B']_sim = clip(M_kind·[R'G'B']_linear)`；再 gamma 编码。矩阵取自 Machado, Oliveira & Fernandes (2009) severity=1.0：

```
M_deutan = [[0.367322, 0.860646, -0.227968],
            [0.280085, 0.672501,  0.047413],
            [-0.011820, 0.042940, 0.968881]]
M_protan = [[0.152286, 1.052583, -0.204868],
            [0.114503, 0.786281,  0.099216],
            [-0.003882,-0.048116, 1.051998]]
```

WCAG 相对亮度 `Y = 0.2126R'+0.7152G'+0.0722B'`，对比度 `(Y_hi+0.05)/(Y_lo+0.05)`；背景 `#332B28`（Y=0.0225）与 `#1B1715`（Y=0.0069）。

| 血 | `#D0342C` | 47.0 | 2.78:1 | 3.57:1 | `#413305` | 22.0 | `#201A06` | 9.5 |
| 酸 | `#B7E22B` | 84.3 | 9.18:1 | 11.80:1 | `#D2A50D` | 69.9 | `#DDA700` | 71.6 |

- `水-能量` deutan 从 23.4 提到 **52.7**（protan 20.8），临界塌缩解除一半；取严分组：<12→5，<20→5，<25→**4**，达到 BRIEF「色盲至少 4 组」。

- `血` 仍是 2.78:1（未过 3:1）且 protan L*=9.5：这是**红色相在暗底的物理下限**，换色无解（见 3.4）。

### 3.3 亮度排序与 ΔY<0.05 对（director 指定）

**推荐 6 色，Y=WCAG 相对亮度：**

| 模式 | 亮度排序（高→低） | ΔY<0.05 的对 |
|---|---|---|
| 正常 | 酸 .646 > 毒 .439 > 油 .384 > 能量 .366 > 水 .360 > 血 .160 | 能量-水 .006；油-能量 .018；油-水 .024 |
| deutan | 酸 .406 > 毒 .154 > 油 .149 > 能量 .148 > 水 .123 > 血 .035 | 油-能量 **.001**；毒-油 **.005**；毒-能量 .006；水-能量 .025；油-水 .026；毒-水 .031 |
| protan | 酸 .430 > 毒 .204 > 水 .172 > 油 .112 > 能量 .089 > 血 .011 | 油-能量 **.023**；毒-水 **.032** |

**结论（必须兜底的两对）**：`毒-水`（deutan .031 / protan .032，两种模式都同亮度）与 `油-能量`（deutan .001 / protan .023）**在两种色盲下亮度都拉不开**，只能靠色相（ΔE_deut 分别 130.4 / 85.4）或形状兜底；`毒-油` 只在 deutan 下同亮度（.005），protan 下拉开到 .092。所有 ΔY<0.05 的配对都不得只靠亮度区分。

### 3.4 塌缩与替代色建议

| 问题 | 证据 | 替代方案（保持语义） |
|---|---|---|
| 毒-油 在 deutan 塌缩 | ΔE=4.9，ΔL*=0.7，ΔY=0.005 | 油提亮到 `#D9A62E`（L*71.0，deutan `#937309` L*50.1）或毒压暗；或接受 4 组，靠形状兜底 |
| 水-能量 临界塌缩 | deutan ΔE=23.4（<25） | 能量 288°→320° `#FF6BD6`，deutan ΔE 提到 52.7，仍保留"电/能量"品红语义 |
| 血 protan 消失 | protan `#201A06`，L*9.5，Y=0.011，对比 1.19:1；提亮到 `#E8605A` 也只有 1.08:1 | 保留血色 + **常量 1px 轮廓 `#E8E0D8`**（L*89.6，10.60:1；protan 模拟 `#C4BEAE` L*77.1，7.46:1）。轮廓不随数据变化，不占编码通道 |
| 血红正常视觉对比不足 | 2.78:1（<3:1） | 同上轮廓；或填 `#D14A42`（3.14:1，但 protan 仍 1.15:1，收益小、语义变亮） |
| 若必须让血色在 protan 下作为"颜色"可见 | 唯一可行区间是粉红 `#FFB3C1`（protan L*55.6，3.76:1） | **不采用**：语义从"血"变成"粉"，6 色语义崩塌；记录为反例 |

> 色盲模拟是近似（Machado 矩阵在极端色上会 clip）；但"红在暗底上 protan 亮度趋近 0"这一结论在 Viénot/Brettel 类模型下同样成立，不依赖单一矩阵。

## 4. 冲突矩阵（I1–I6 两两）

记法：`通道`=两属性抢同一通道（C2 硬冲突）；`间距`=不抢通道但像素间距 ≤1px（感知冲突）；`—`=无。字母 A/B/C 表示该方案存在此冲突。

| | I2 温度 | I3 含量 | I4 射程 | I5 状态 | I6 方向 |
|---|---|---|---|---|---|
| **I1 成分** | A:通道(明度)<br>B:通道(形状) | B:通道(形状×密度) | C:间距(纹理压色块) | — | B:通道(头形vs形状族)<br>C:通道(形状类vs箭头) |
| **I2 温度** | — | A:间距(芯在填充区内)<br>B:通道(符号×网点)<br>C:间距(槽位×刻度) | B:—<br>C:— | A:通道(明度vs环亮度)<br>C:间距(左槽×环 0px) | B:间距(符号×上/右头 1px)<br>C:间距(左槽×左头 0–1px) |
| **I3 含量** | | — | A:间距(刻度像额外体积)<br>C:通道(数量×纹理) | A:间距(填充贴 1px 墙) | — |
| **I4 射程** | | | — | A:间距(y14 刻度×y15 环 0px)<br>C:通道(虚线穿环) | A:间距(下头 y11–13×刻度 y14 0px)<br>C:间距(纹理×箭头) |
| **I5 状态** | | | | — | —（头始终在环内 2px） |

**计数**：A 有 6 处冲突（其中通道级 1 处：I1×I2 明度；其余 5 处均为 ≤1px 间距）；B 有 5 处（通道级 3 处：形状被 I1/I2/I6 三个属性占用）；C 有 8 处（通道级 2 处：形状、数量×纹理；间距 6 处）。**A 的通道级冲突最少**，这是推荐 A 骨架的直接理由。

**关键冲突点（必须靠坐标或顺序解决的 4 处）**：
1. `I1×I2`（A）：体色 L* 47–84 跨 3.7 档，温度芯 ΔL* 只有 16.5–20.9 → 芯的"冷/热"会被体色明度带偏。**解决**：温度改用符号（推荐轨），明度整条让给 I1 的 CVD 冗余。
2. `I2×I6`（B）：温度符号 4×4 在 (1,1)，上向头在 (7,2)，右向头在 (11,7)；上/右头与符号最小间距 1px。
3. `I4×I5`（A）：刻度 y=14 与 1px 环 y=15 **0px 间距**；1x 下刻度会被读成环的缺口。
4. `I4×I6`（A）：下向头 y=11–13，刻度 y=14，0px；下向时"头+刻度"连成一条 5px 亮带，读成"尾巴"。

## 5. 推荐方案与 Tier-0 降级轨

### 5.1 完整轨（假设未来获得 `Composition(6)/RangeRemaining/State`，属"需用户批准的只读数据前置任务"）

| 信息 | 通道 | 编码（像素级） | quads |
|---|---|---|---|
| I1 成分 | 色相（+ 常量轮廓） | 体 6×6 填充 6 色（§3.2）；外圈 1px `#E8E0D8` 常量轮廓 | 4（轮廓）+1（填充） |
| I2 温度 | 符号 | 4×4 于 (1,1)–(4,4)：雪 X（冷）/ 横杠（常温）/ 火焰三角（热）；12 px² | ≤5 |
| I3 含量 | 体积（面积） | 体内部 4×4 填充 1/2/4 行 = 4/8/16 px²；空=0 | 1 |
| I4 射程 | 数量 | y=14，x=1/3/5 三个 1px 刻度；1/2/3 个 = 3 档 | 3 |
| I5 状态 | 边框 | 1px 环 60 px，5 图案（全实/上缺口/下缺口/左右缺口/点线）；**只用中性色，禁止用成分色** | ≤4 |
| I6 方向 | 位置 | 3×3 头 4 向：上 (7,2)/下 (7,11)/左 (2,7)/右 (11,7)；不旋转、不位移体 | 3 |

**布局账**：16×16=256 px²；图标 12×12=144 px²；体 6×6 在 (5,5)–(10,10)；最坏不透明覆盖 = 体 36 + 头 9 + 温度 9 + 刻度 3 = **54/144 = 37.5% 图标面积**（C5 需实测，见 H1）。总 quads = 4+1+5+1+3+4+3 ≈ **20 ≤ 32**（硬上限 64），单材质 1 draw call，稳态 0 alloc。

**为什么是这套（对照三套）**：
- 取 A 的骨架（0 同通道复用、静态可读、quads 最低），只把 A 最弱的 I2 从"明度"换成"符号"——因为 I1 的 6 色明度跨 3.7 档，明度已被 I1 的 CVD 冗余占用；符号是 11 条通道里唯一"静态、绝对、不与色相/面积/数量/边框/位置冲突"的还剩项。
- 取 B 的色盲思路但不取形状：形状在 4×4 内只能 3 种，却要同时服务 I1/I2/I6，C2 必违规。
- 取 C 的静态温度思路但不取位置：位置要给 I6，且左列槽位与左向头重叠 1px。

### 5.2 Tier-0 降级轨（只用现有可读量）

现有可读：`Temperature`（-20..100）、含量、方向 4、运动/静止、出生/消失。**不可得**：6 分量成分（只有 `Moisture`）、剩余射程、状态细分（受阻/分流/汇聚/被收集）。假设：`Moisture` 作为"含水占比 0..1"可读。

| 信息 | Tier-0 处理 | 通道 | 编码 |
|---|---|---|---|
| I1 成分 | 降级为"含水占比" | 色相（固定水蓝）+ **饱和度** | `#3FA9F5` 固定色相，S=0.15/0.55/0.95 → `#D0E5F5` L*89.9 / `#6EBDF5` L*73.7 / `#0C94F5` L*59.8（ΔL* 16.2/13.9；饱和度是 I1 专属子通道，完整轨里变常量，不重排） |
| I2 温度 | 完整保留 | 符号 | 同 5.1（4×4 三符号），静态可读 |
| I3 含量 | 完整保留 | 体积 | 同 5.1（1/2/4 行）；若"含量"实际不可读，则整条空出 |
| I4 射程 | **不可得** | —（空） | 不显示，不做"假射程"（如尾迹长度），避免未来加字段时重排 |
| I5 状态 | 降级为"动/停" | 运动（物理事实，非编码） | 只表达 流动/静止；受阻/分流/汇聚/被收集**不可得**，不用闪烁或边框假装 |
| I6 方向 | 完整保留 | 位置 | 同 5.1 |
| 出生/消失 | 存在性 | alpha 0→1 / 1→0，2 帧 | 常量过渡，不承载任何属性 |

**Tier-0 下不得占用的通道（为未来数据预留）**：

| 保留通道 | 未来归属 | 若现在占用的后果 |
|---|---|---|
