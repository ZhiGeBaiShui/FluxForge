## 1. 原版依据

原版不是每天一个新剧情。

`StoreClientManager.HandleAlwayClient()`：

```csharp
if (12 == dayCounter && !isAugIntroduced)
    AddClient(CreateMentorShotgun());

if (24 == dayCounter && !hasBusinessPermit)
    AddClient(CreateMentorPermit());

if (38 <= dayCounter && dayCounter % 7 == 3 && !hasBusinessPermit)
    AddClient(CreateBusinessPermit());
```

剧情客户由：

```text
特定天数
未完成 flag
周期
玩家身份/行为
```

触发，且原版不少剧情客户 `dismissable = false`，强制听完。

本 Mod：

```text
保留条件驱动、低频
不保留不可拒绝
```

## 2. 邀请模型

### 2.1 邀请是一个普通客户

```text
dismissable = true
玩家不接待，他等一会儿自己走
走掉即 declined
不扣钱、不扣声望、不写后续
```

不是弹出任务框。

### 2.2 玩家可以不理

```text
邀请出现 → 玩家可以直接继续做自己的事
不点击、不对话、不选择
客户自己离开
```

这比“必须点拒绝”更自由。

### 2.3 玩家可以拒绝

如果玩家主动对话：

```text
“99% 酸，低残留，20 单位。你有设备。”
选项：
  1. 报价
  2. 这批不做
  3. 问规格
```

拒绝：

```text
NPC 交易性收尾：“行。要货的时候再来。”
不追问
不扣关系
不写 step
```

### 2.4 玩家可以中途退出

```text
每个节点至少一个“到此为止”
退出后链 ended
不生成后续节点
```

## 3. 链槽位

### 3.1 不再全局独占

```text
每个 NPC 最多一条 active 链
全局最多两条 active 链
```

Oya、Vera、采购员可以各自有正在进行的线。

### 3.2 挂起而不是消失

如果新邀请出现时槽位已满：

```text
写 chain.<id>.pending
不按日期过期
下一次该 NPC 到访时优先出现
不会重复刷屏
```

验收：

```text
接了一条链，不会导致其他链的邀请永久消失
```

### 3.3 已结束的记录

终端/账本可以有一页：

```text
已经了结的事
X 日：上层采样，我拒绝了。
```

没有红点、没有感叹号、没有“未完成”。

拒绝被记录，但不被追讨。

### 3.4 节点推进节奏

```text
节点推进 = 该 NPC 下一次到访
通常 1–2 个游戏日
且必须满足节点自己的前置
```

例子：

```text
procurement 节点 2：
  采购员下一次来 + 玩家手上有 20 单位 99% 低残留酸

vera_supply 节点 2：
  薇拉下一次来 + 玩家决定继续供货

oya_past 节点 2：
  奥雅下一次来 + 玩家上次选择了“继续问”
```

不再写“2–4 天”，也不按固定日期。

玩家没有满足前置：

```text
节点不推进
邀请保持 pending
不消失、不扣钱、不催促
```

## 5. 前 20 天

不做每日排期表。

```text
第 1 天：奥雅教程（既有）
第 2 天以后：普通营业
```

前 20 天最多 **5 条剧情内容**，但其中只有 **3 条是 P0 链**：

```text
1. chain.procurement       P0，第一次低残留交付后
2. chain.vera_supply       P0，玩家主动报价/批量交易后
3. chain.return            P0，卖出问题货后
4. former_intro            上架对话，不占链
5. chain.custom_order      P1，需要终端
```

其余 P0 链按行为解锁：

```text
chain.former_order         买成型机后
chain.inspection           风险交易/主动查记录
chain.oya_past             买成型机 + 主动问
chain.upper_contract       完成 2 次采购
chain.black_market         旧厂/受限化学品
```

允许玩家连续 3 天不接任何链。

第 4 天不得出现：

```text
催促
补偿
“你错过了”
自动替代剧情
```

## 6. 12 条链

### 6.1 chain.procurement：上层采样

**触发**

```text
玩家第一次交付 99% 低残留酸之后的下一次开门
```

**节点 1**

```text
采购员：“99% 酸，化学残留低于 1%，20 单位。你有设备。”
选项：
  1. 报价
  2. 这批不做
  3. 问规格
```

**节点 2**

```text
交付后：
  1. 长期供应（价格 +10%，但每 7 天固定要货）
  2. 单次高价（本次 +30%，之后概率降低）
  3. 到此为止
```

**拒绝**

```text
“行。要货的时候再来。”
无惩罚。
```

### 6.2 chain.vera_supply：低价供货

**触发**

```text
玩家主动向薇拉报价，或完成一次批量交易
```

**节点 1**

```text
薇拉：“预算低。你卖上层是卖，卖我也是卖。”
选项：
  1. 接低价单
  2. 这批不做
  3. 要求预付
```

**节点 2**

```text
连续供货：
  1. 保供（关系 +1，单价 -10%）
  2. 涨价（现金 +30%，关系 -1）
  3. 到此为止
```

**拒绝**

```text
薇拉：“行。有货再找我。”
```

### 6.3 former_intro：成型机上架对话

> 不占剧情链槽位；只是奥雅库存上新。

**触发**

```text
奥雅二次到访，玩家查看货架上的成型机
```

**节点 1**

```text
奥雅：“我自己改的。纯化液按配方压成成品，耗电。”
选项：
  1. 问价格
  2. 问配方
  3. 不买
```

**节点 2**

```text
购买后：
  奥雅：“配方别乱改。炸了别说是我的机器。”
```

**拒绝**

```text
机器留在奥雅库存，不催。
```

**明确代价**

```text
买成型机 = 开启 former_order 和 oya_past 两条 P0 线
不买 = 这两条链不启动，但原料线照常
```

奥雅上架时直接说：

```text
“这台机器会开两条线：成品单，和旧厂的事。买不买随你。”
```

不隐藏 gate。

### 6.4 chain.former_order：成品订单

**触发**

```text
玩家已有成型机，奥雅下一次到访主动提到有客户问成品
或采购员询问成品
```

**节点 1**

```text
采购员：“有没有助熔剂成品？”
选项：
  1. 接单
  2. 只卖原料
  3. 这批不做
```

**节点 2**

```text
交付：
  1. 收现金 +200
  2. 换长期采购名额：
     每 7 天固定收 20 单位，单价 +10%
     持续 28 天
  3. 到此为止
```

**拒绝**

```text
“行。原料也收。”
不降价。
```

### 6.5 chain.return：退货

**触发**

```text
玩家把含沉淀/化学残留的货卖给薇拉
```

**节点 1**

```text
薇拉把瓶子放回柜台：“这批有沉淀。”
选项：
  1. 退款
  2. 换货
  3. 按合同走（不认这批）
  4. 到此为止
```

**后果**

```text
退款：现金 -80，关系不变
换货：库存 -1 批，关系 +1
按合同走：现金不变，关系 -1
```

不写“拒绝负责”。

### 6.6 chain.inspection：抽检

**触发**

```text
玩家有风险交易，或主动去站务窗口查记录
```

**节点 1**

```text
检查员：“最近三天的出货记录。”
选项：
  1. 配合
  2. 贿赂（300）
  3. 给站长办公室打电话（500，或消耗 1 次人情）
  4. 关门，改天再说
```

**人情来源**

```text
完成一次 procurement 链 +1 人情
最多存 2 次
```

**后果**

```text
配合：固定罚款 150，风险 0
贿赂：现金 -300，风险 +1
打电话：现金 -500 或人情 -1，检查取消
关门：当天营业损失，固定 5 天后必回，风险不涨
```

有钱人解法明码标价。

### 6.7 chain.oya_past：旧厂

**触发**

```text
玩家买成型机后，主动问奥雅“机器哪来的”
```

**节点 1**

```text
奥雅：“旧厂拆出来的。”
选项：
  1. 继续问
  2. 不追问
  3. 只谈买卖
```

**节点 2**

```text
继续问：
  奥雅给一个名字/供应商地址
  信息 +1
不追问：
  当场拿到一句有用的话（例如“别买北环的酸”）
  不是永久损失
```

### 6.8 chain.upper_contract：上层合同

**触发**

```text
完成 2 次采购链，玩家主动联系采购员
```

**节点 1**

```text
采购员：“上层要签独家。”
选项：
  1. 签
  2. 不签
  3. 买非独家配额（800）
  4. 到此为止（这条线不接）
```

**后果**

```text
签：采购价 +15%，薇拉/黑市订单 -50%
不签：采购价不涨，无优先配额；薇拉/黑市照常
买配额：现金 -800，保留全部渠道，采购价 +8%
        约 40 次交付回本
到此为止：与“不签”相同，无额外惩罚
```

“不签”和“到此为止”不再有两种价格。

### 6.9 chain.black_market：黑市

**触发**

```text
玩家库存出现受限化学品，或 oya_past 完成
```

**节点 1**

```text
薇拉：“有人要一批不登记的酸。”
选项：
  1. 接
  2. 不接
  3. 只做中间人（抽 20%）
  4. 问用途
```

**后果**

```text
接：现金 +400，检查风险 +1
不接：薇拉不劝
中间人：现金 +80，风险 0，薇拉关系 -1
问用途：信息 +1，薇拉警惕
```

信息 ≥2 时：

```text
“问用途”直接拿到具体买家名
后续 custom_order 可向该买家挂单
```

没有“举报”假按钮。

### 6.10 chain.blackout：停电

**触发**

```text
Day 20 后的站台环境事件
```

**节点 1**

```text
奥雅：“上层把电切了。冷萃和离心都停了。”
选项：
  1. 用手头库存保供
  2. 涨价
  3. 关门
```

**后果**

```text
保供：现金低，薇拉关系 +1
涨价：现金 +50%，薇拉关系 -1
关门：无收入，风险 0
```

不写成“救援病人”。

### 6.11 chain.rival：同行报价（P1，并入 upper_contract）

> 不单独占一条 P0 链；作为 upper_contract 的定价分支。

**触发**

```text
完成 2 次采购后，玩家在终端看到同行报价
```

**节点 1**

```text
采购员：“有人比你便宜 15%。”
选项：
  1. 跟价
  2. 不跟
  3. 找同行谈合作
  4. 到此为止（这条线不接）
```

**后果**

```text
跟价：现金 -15%，保住订单
不跟：订单 -30%，价格不变
合作：双方分单，现金 +10%，需要关系 2
到此为止：订单不变，不追这条线
```

### 6.12 chain.custom_order：柜台挂单（P1）

> 需要终端/挂单 UI；P0 不做。

**触发**

```text
玩家在柜台终端发布求购/出售挂单
```

**节点 1**

```text
玩家自己填：
  品类
  数量
  价格
```

**结果**

```text
24–48 小时后有人来，或没人来
没人来也是结果，不是失败
```

这是玩家发起，不是 NPC 发起。

### 6.13 环境事件：shortage

> 不占剧情链槽位，不要求玩家接受。

**触发**

```text
Day 12 后，站台短缺事件
```

**内容**

```text
广播：下环水处理延迟，净化用品短缺。
薇拉/采购员的收购价随之上浮。
```

玩家可以：

```text
1. 提高售价（现金 +25%，薇拉关系 -1）
2. 维持原价（现金不变，薇拉关系 +1）
3. 停卖（库存保留，无关系变化）
```

没有后续节点，事件过去即结束。

## 8. 数值

关系（薇拉）：

```text
0 = 不合作
1 = 普通收购
2 = 优先供货
3 = 可赊账/预付
```

检查风险：

```text
0 = 无
1 = 可能抽检
2 = 抽检概率高
3 = 下次必查
```

信息：

```text
0 = 无
1 = 一个具名买家
2 = 一个原料来源
3 = 一个上层渠道
```

现金全部写单位，不用“关系+”这种空词。

## 11. 验收

```text
1. 玩家连续 3 天不接链，第 4 天无催促/补偿/替代剧情。
2. 邀请客户可以不理，自己离开，无惩罚。
3. 每条链入口有“不做”，每个节点有“到此为止”。
4. 拒绝后不写 step，不自动续接。
5. 拒绝不扣钱、不扣关系、不影响其他链。
6. 接一条链不会让其他邀请永久消失；pending 不按日期过期。
7. 前 20 天最多 5 条链可用。
8. 8 条 P0 链中至少 2 条由玩家主动动作触发；另 2 条 P1 需要 UI。
9. 成型机只加入奥雅库存，不免费送。
10. upper_contract 拒绝后仍可向采购员卖货，只是价格/概率变化。
11. inspection 的关门损失明码标价，5 天后必回。
12. 所有结果有现金/库存/风险/关系数值，不用空泛形容词。
```

全局一条 active 挤掉其他链
