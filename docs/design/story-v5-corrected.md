## 0. 修正清单

### 0.1 化学用品没有管制

删除：

```text
chain.inspection        抽检/罚款/贿赂
chain.black_market      黑市/受限化学品/举报
chain.upper_contract    上层合同/独家配额
“未登记化学品”的所有台词
```

保留：

```text
化学品是难以查验的原料
高浓度酸/碱稀缺
买家只能看浓度、外观、沉淀和供货记录
```

### 0.2 奥雅是发明家，不是导师

修正：

```text
流源工艺的大部分基础研究由奥雅完成
她卖机器、改进机器、做原型
她不是玩家的导师
开局与玩家交涉很少
不会主动给玩家大量帮助
```

她的台词只谈：

```text
机器
结构
耗电
配方
价格
```

不谈：

```text
“你应该……”
“我教你……”
“这是为你好……”
```

### 0.3 薇拉是上层医学家

修正：

```text
身份：上层区医院的医学研究者
需求：酸碱用于医药品/实验
性格底色：善良，但不了解下环生活
被售卖方坑过，所以原料污染严重
开局不提及她对上层区以外环境的认知
```

删除：

```text
“下环诊所”
“我姐姐的诊所”
“病人需要这批货”
“预算低所以只能买差的”
拿病人当情感筹码
```

保留：

```text
她需要稳定的高纯度酸碱
她知道自己的原料被掺了东西
她不知道下层怎么活，也不假装知道
```

### 0.4 没有化学工厂剧情

删除：

```text
北环水处理厂
旧厂/前雇主/揭发
化学工厂订单
```

保留：

```text
流源工艺是小众手艺
高浓度化学用品稀缺
奥雅是这项手艺的主要研究者之一
```

### 0.5 经济数值校正

游戏内实际：

```text
flux_agent         unitValue = 4
advanced_flux_agent unitValue = 300
薇拉收购酸/碱     约 10 信用点 / 100 mL（99%）
薇拉收购 90–98.9% 约 5 信用点 / 100 mL
高纯度交易          单次交货中 >=99% 液体总计 >=100000 单位（100 mL）触发高浓度对话
化学试剂瓶         250 mL
成型机             300 信用点
```

所以：

```text
4 mL 重金属 → 1 个 flux_agent
1 个 flux_agent 卖 6 信用点，不是 200
20 个 flux_agent 订单 = 120 信用点
成型机 300，需要约 50 个 flux_agent 回本
```

不再写“4 mL 小助熔剂换 200”。

## 2. 薇拉周合同

### 2.1 触发

```text
100000 单位（100 mL）只触发高浓度对话，不触发合同
合同触发条件待定
```

不是 Day N。

### 2.2 提议

```text
“这次不是零买。”
“我在上层区的中心医院做药。”
“医院那边的供应商又出问题了。浓度不够，杂质也多。”
“我拿你上次的样做过对比。你的能用。”
“医院想找个固定供货的。”
```

玩家选项：

```text
1. “你想怎么供？”
2. “我只做零散。”
3. 不说话，等她继续
```

选 1：

```text
“单子你看一下。”
“每周一批。最少 300 毫升，99% 以上。”
“酸、碱都行。酒精也行，单子上有。”
“周三我把医院用不了的原料带来，周六取货。”
“原料不要钱。货按品质算。”
“最少三百毫升。多了我也收。”
“你一个人做这些？忙得过来吗？”
“你考虑一下，不急着现在答。”
```

选 2：

```text
“行。那我还是零买。”
```

合同不启动，无声望损失，日常收购照常。

选 3：

```text
“医院用不掉的，弃了也是弃了。你要能提纯，算你的。”
```

### 2.3 周三：送原料

薇拉带来：

```text
2–4 瓶受污染酸/碱原料
每瓶 250 mL
污染程度取决于医院声望
```

医院声望低：

```text
3–4 瓶，污染重
```

医院声望高：

```text
2–3 瓶，污染轻
```

玩家选项：

```text
1. 收下
2. 只收一部分
3. 这周不接
```

选 3：

```text
薇拉把原料带走。
本周不扣声望，但合同进度停一周。
```

### 2.4 周六：取货

薇拉检查后柜台：

```text
要求：300 mL 酸/碱，99% 以上
按实际浓度和数量结算
```

结算：

```text
基础价：10 信用点 / 100 mL
99.5% 以上：×1.5
100%：×3
未达标：不付款，医院声望 -8
达标：医院声望 +4
超额/更高纯度：医院声望 +6
```

上限：

```text
医院声望 0–100
```

声望影响：

```text
0–24    原料污染重，合同量小
25–49   原料污染中等
50–74   原料污染轻，合同量 +100 mL
75+     可谈更高单价/更少污染
```

### 2.5 合同失败

如果连续 2 周未达标：

```text
薇拉暂停合同
不永久拉黑
玩家可以之后重新谈
```

如果玩家主动退出：

```text
无声望惩罚
薇拉继续零散收购
```

### 2.6 为什么不是“每日任务”

```text
一周两次固定接触：周三送料、周六取货
中间几天没有剧情催促
普通客户照常
```

## 3. 八条 P0 剧情

### 3.1 第一次交付

**触发**

单次交货中 >=99% 的酸/碱总计达到 100000 单位（100 mL）。

只在达到门槛的那次交易后触发一次，不累计多次小额交货。

**场景**

```text
“你好，我来收些化学试剂。”
“我收购的化学试剂总是带着较高的污染。”
“九十以上就行。”
“浓度越高越好，我会提供报酬。”
```

若本次交易 >=99%，且是第一次高浓度交易：

```text
“这么高的浓度，你怎么做到的？”
```

玩家选项：

```text
1. “自己做的。”
2. “运气好。”
```

分支 1：

```text
“手艺不错呀。”
```

分支 2：

```text
“那希望你每次都能有这样的好运气。”
```

回答完回到交易选项，不插“这些我收下了/多谢”这类结束语。

若本次交易 <99%：

```text
“还缺一些更高浓度的试剂，我再去其他地方找找。”
```

作用：

```text
建立“高纯度酸有稳定买家”的认知
表现薇拉的善良，但不让她评价下环/道德
不引入导师式教学
```

### 3.2 医院周合同

见第 2 节。

### 3.3 奥雅成型机上架

**触发**

奥雅下一次到访，玩家查看货架。

**场景**

```text
“我改了台成型机。”
“流源工艺这套东西，最早是我先做的。”
“纯化后的液体倒进去，按配方压成成品。耗电。”
“今天起放货里。买不买随你。”
```

玩家选项：

```text
1. 问价格
2. 问配方
3. 不买
```

不买：

```text
机器留在奥雅库存。
不催，不写“你会后悔”。
```

买：

```text
扣除 300 信用点
加入玩家设备
```

### 3.4 成型机助熔剂订单

**只由奥雅发出。薇拉不买助熔剂，也不参与这条订单。**

**触发**

玩家有成型机后，奥雅下一次到访，把一小袋重金属粉末放在柜台上。

```text
“机器买了吧？”
“帮我做二十个助熔剂。四毫升一份，纯重金属。”
“一个六块。做完我来拿。”
```

价格：

```text
1 个 flux_agent = 6 信用点
20 个 = 120 信用点
```

玩家选项：

```text
1. 接 20 个
2. 只做 5 个
3. 这批不做
```

如果接：

```text
需要 80 mL 100% 重金属
消耗 20 电
交付 20 个 flux_agent
```

拒绝：

```text
奥雅把袋子收回去：“行。我自己磨。”
不扣关系，不追杀。
```

### 3.5 坏批次退货

**触发**

玩家给薇拉的合同货中，有一瓶低于 99%，或化学残留过高。

**场景**

```text
“这批不行。”
“瓶底有沉淀。”
“你换一批，或者这周不算。”
```

玩家选项：

```text
1. 换货
   库存 -1 批，声望不变
2. 退款
   现金 -50，声望 -2
3. 这周不交
   声望 -8，合同继续
4. 到此为止
   结束本次交付
```

没有“拒绝负责”这种道德按钮。

### 3.6 原料短缺

**触发**

站台原料供应波动，薇拉周三带来的原料减少。

**场景**

```text
“这周上游只给了这些。”
“你要少做一点，还是用更脏的原料？”
```

玩家选项：

```text
1. 少做，按实际交货
   声望 +2，收入低
2. 用更脏的原料，尽量凑量
   有概率不合格，声望风险
3. 这周不接
   声望不变，合同暂停一周
```

这是供应问题，不是道德问题。

### 3.7 奥雅原型测试

**触发**

玩家买了成型机后，奥雅主动提一次：

```text
“我做了个新过滤器原型。”
“你拿一批脏酸试，数据给我。机器先借你。”
```

玩家选项：

```text
1. 试
2. 不试
3. 问报酬
```

试：

```text
获得临时原型过滤器
完成一次高污染酸处理后
奥雅给 30 信用点/一台旧装置
```

不试：

```text
“行。我自己找别人。”
不扣关系，链结束。
```

奥雅不是导师：

```text
她只要数据
不教玩家“应该怎么玩”
```

### 3.8 医院质量复核

**触发**

医院声望达到 25 后，薇拉提出一次内部质量复核。

**场景**

薇拉把一张复核表放在柜台上。

```text
“医院每年都要走一遍。”
“不是站务那边。就我们医院。”
“你最近三批的出货记录，有吗？”
```

玩家选项：

```text
1. 给出记录
   声望 +4
2. 只给部分记录
   声望 +0，薇拉记下
3. 拒绝
   声望 -4，合同继续
```

没有罚款、没有逮捕、没有“化学管制”。

这是买家对供应商的质量确认。

### 3.9 合同续签

**触发**

医院声望达到 50 后，薇拉主动提出续签。

**场景**

```text
“医院这周排的班多，三百毫升见底了。”
“我能把合同提到五百。价格加一成。”
“你那边做得过来吗？”
```

玩家选项：

```text
1. 接 500 mL
   收入提高，失败时声望损失更大
2. 维持 300 mL
   收入不变，稳定
3. 不续签
   合同保持原样，链结束
```

续签后：

```text
每周要求 500 mL，99% 以上
达标：声望 +6
失败：声望 -10
连续 2 周失败：暂停合同
```

不是强制升级；玩家可以拒绝，不扣声望。
