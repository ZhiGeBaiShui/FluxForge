# 玩家视角评审 v1

> 本文评审的是已废弃的道德向设计；当前基调设计见 [dark-tone-storyline.md](dark-tone-storyline.md)。

> 本评审针对加长前的 v1 设计；设计稿第 10 节已吸收 Q2、Q4、Q5、Q6、Q12 和诊所伏笔的修改。

## 结论

总分：**7/10**

- 第一幕：8/10
- 第二幕：7.5/10
- 第三幕：6.5/10
- 日常：7/10

我愿意玩完第一幕和第二幕，但**第三幕的很多情绪来自我还没见过的角色**，会有“被要求关心陌生人”的感觉。

---

## 1. 前 30 分钟

**喜欢：**

```text
Q1 很快：教程酸还能继续提纯，卖给薇拉。
这里我知道自己在干什么：升温、净化、放后柜台。
```

**问题：**

```text
Q2 的旧离心机是“剧情赠送”，但我还没理解净化为什么不够。
如果直接送，我会觉得是在按剧本走，而不是自己发现工具不够。
```

**改进：**

```text
Q2 先让我用净化装置处理薇拉的脏酸，得到 80–90%，
薇拉拒收，奥雅才拿出离心机。
让工具需求从失败里长出来，不要先送再解释。
```

## 2. 第一幕逐条

### Q1 第一笔真订单

**喜欢：**

```text
交易完成就推进，没有订单 UI。
“以后我每天都会来”让我知道这是一个可持续循环。
```

**问题：**

```text
我刚做完 95% 教程，薇拉立刻要 99%，
如果我不知道继续升温+净化就能做到，会卡住。
```

**改进：**

```text
薇拉第一次拒绝时，给一个明确但不说教的提示：
“净化前先把温度提上去。温度不够，纯度上不去。”
```

### Q2 分离第一课

**喜欢：**

```text
挂在奥雅二次剧情后的 VisitEnding，避免再等七天。
旧离心机有“导师把旧工具交给你”的感觉。
```

**问题：**

```text
净化装置只去化学污染/重金属，这个限制是系统知识，
但剧情里没有先让我踩一次坑。
```

**改进：**

```text
加一个 30 秒的失败：脏酸净化后仍是浑浊/被薇拉退回，
奥雅再解释“净化不是万能”。
```

### Q3 碱也要

**喜欢：**

```text
酸→碱的迁移自然，薇拉“照样收”符合人设。
```

**问题：**

```text
和 Q1 太像：再做一瓶、再卖一次。
没有新选择，只是换了个液体。
```

**改进：**

```text
让碱第一次出现“买家用途冲突”：
薇拉要碱做清洁剂，奥雅怀疑同一批碱会进医疗线。
玩家选择先问用途，还是直接收钱。
```

### Q4 第一张长期合同

**喜欢：**

```text
“各 100 mL”比“再做一瓶”更像生意。
```

**问题：**

```text
仍然只是交付，没有谈判。
玩家没有拒绝、压价、要求预付的选择。
```

**改进：**

```text
加一个三选一：
A. 接受固定低价，稳定
B. 要求涨价，薇拉信任下降
C. 要求先付材料费，需要之前如实记录的 flag
```

### Q5 把流程固定下来

**喜欢：**

```text
250 mL 99.5% 是一个明确的产能目标。
奥雅“你是在做生意”这句能立住导师身份。
```

**问题：**

```text
500 mL/250 mL 的重复操作会变成体力活。
如果装置速度慢，这里会明显卡住。
```

**改进：**

```text
把目标降到 150–200 mL，或允许分两天交付。
重点应是“稳定”，不是“量大”。
```

## 3. 第二幕逐条

### Q6 加急单

**喜欢：**

```text
第一次把“快”和“稳”放在一起，薇拉的语气变化很好。
```

**问题：**

```text
赶工和复检目前只是 flag，玩家在当下感觉不到差别。
两条路都要交 250 mL，选择像文本选择，不像玩法选择。
```

**改进：**

```text
赶工：当天能交，但第二天薇拉会带来“有沉淀/被退回”的消息；
复检：晚一天交，薇拉不耐烦，但后续少一次事故。
让时间成本真的存在。
```

### Q7 奥雅的旧样品

**喜欢：**

```text
这是全篇最好的钩子。
“北环水处理厂”把装置来源和污染主题连起来了。
```

**问题：**

```text
“检测”没有操作感。
如果只是对话选项，玩家会觉得这是选立场，不是做化学。
```

**改进：**

```text
让玩家真的拿一瓶旧样品做一次升温/净化/离心，
看到异常残留，再决定是否继续查。
检测结果最好用一个简单视觉/数值反馈，而不是纯文本。
```

### Q8 薇拉的审核

**喜欢：**

```text
如实记录/伪造记录/拒签，三个选项都能理解。
```

**问题：**

```text
审核本身没有场景。
“写记录”只发生在对话里，玩家没有看到记录、也没有看到风险。
```

**改进：**

```text
加一个很短的“出货单”道具/文本界面，
让玩家看到自己要签的字，再选择。
不需要新系统，一个 Dialogue/Note 就够。
```

### Q9 泄漏

**喜欢：**

```text
召回/压下/去诊所，选择有分量。
```

**问题：**

```text
如果玩家一路谨慎，仍然会“有货出问题”，会觉得被剧本强行制造冲突。
```

**改进：**

```text
谨慎路线改成“近失”：
玩家在出货前发现异常，问题变成“要不要主动告诉薇拉”。
这样既保留事件，又不惩罚谨慎。
```

### Q10 北环的报价

**喜欢：**

```text
“别再问原料从哪来”很有压迫感。
```

**问题：**

```text
北环从头到尾没有出现过。
我被要求害怕一个只在台词里的公司。
```

**改进：**

```text
在 Q7 旧样品里加入北环的标记/便条，
在 Q9 里让北环的人通过薇拉传话，
至少让玩家见过一次它的“手”。
```

## 4. 第三幕逐条

### Q11 薇拉的选择

**喜欢：**

```text
“诊所是我姐姐开的”把薇拉从收购机器变成了人。
```

**问题：**

```text
姐姐第一次被提到就在要我做重大选择。
我没有任何关于她的记忆，所以这不是情感选择，是信息选择。
```

**改进：**

```text
提前埋 2 次：
Q3 薇拉提到“诊所最近缺货”；
Q6 加急单里她说“这次不是给普通客户”。
到 Q11 再说姐姐，玩家会有“原来如此”。
```

### Q12 最后一批

**喜欢：**

```text
500 mL 99.9% 是一个清楚的终局目标。
```

**问题：**

```text
500 mL 太多了。
如果产线效率不高，这里会从剧情高潮变成重复劳动。
```

**改进：**

```text
降到 300 mL，或者允许分两批交。
把压力放在“选择供谁”，不要放在“再点几次装置”。
```

### Q13 结账

**喜欢：**

```text
三个结局分别对应钱、独立、揭发，方向清楚。
```

**问题：**

```text
结局主要由 flag 组合决定，玩家在最后不知道自己为什么得到这个结局。
“最佳变体”容易变成攻略答案，而不是自然结果。
```

**改进：**

```text
在最终选择前，让奥雅和薇拉各说一句“你这一路做了什么”，
把玩家之前的选择复述出来，再让玩家做最后一次选择。
结局之后给一张简短的“账本”总结：赚了多少、信了谁、失去了谁。
```

## 5. 日常剧情

**喜欢：**

```text
薇拉的日常短句有生活感，适合每天 30–90 秒。
```

**问题：**

```text
奥雅的日常大多是 OpenShop，玩家会感觉“又是来看货”。
薇拉的日常条件大多是 flag，重复玩时变化不够。
```

**改进：**

```text
给奥雅至少两条纯闲聊/回忆日常，不进商店。
给薇拉一条“她记得你上次选择”的反应日常。
同一句日常按 flag 改后半句，比新增十条更有效。
```

## 6. 节奏判断

```text
第 1 天：很好，有明确目标
第 2–3 天：开始重复，需要 Q2 的失败/发现
第 4–5 天：Q4/Q5 的交付量可能让我暂停
第 6–9 天：Q6/Q7 是第二幕最强钩子，我会继续
第 10–14 天：如果 Q12 还是大量重复操作，我可能直奔结局
```

**最可能弃游点：**

```text
Q5 或 Q12 的大体积交付。
```

**最强钩子：**

```text
Q7 奥雅的旧样品。
```

## 7. 最喜欢与最弱

**最强：**

```text
Q7 旧样品 + Q9 召回。
它把“纯度”从数值变成了道德问题。
```

**最弱：**

```text
Q4 第一张长期合同。
它只是 Q3 的加量版，没有新的玩家决策。
```

## 8. 我希望的五个改进

1. **让 Q2 先失败再给离心机**：工具需求从问题里长出来。
2. **提前埋薇拉的姐姐/诊所**：至少两次提及，Q11 才有情感重量。
3. **给 Q4 加谈判选择**：低价稳定 / 涨价 / 预付款，三种后果。
4. **让 Q6 的赶工/复检产生可见后续**：退回、延迟或额外事故，而不只是 flag。
5. **降低 Q5/Q12 的交付体积**：把高潮从“重复操作”移到“选择供谁”。

## 9. 一句话

```text
这是一条有主题、有道德选择的前中期线，
但目前更像“设计者在讲一个关于纯度的故事”，
还不完全像“玩家自己在经营一家会做选择的店”。
```
