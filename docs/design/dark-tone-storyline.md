# 太空站店主：黑暗基调与前期剧情设计

## 0. 方向修正

上一版把“纯度”写成了道德选择：薇拉的诊所、姐姐、揭发北环、召回问题货。

这不符合本 Mod 和原版的底色。

新方向：

```text
玩家不是英雄，也不是受害者。
玩家是一名有店铺、有现金、有设备渠道的店主。
太空站的黑暗不需要玩家去解决；
它只需要被看见，并且可以被玩家利用。
```

玩家身份：

```text
中上层阶级的小店主
有稳定店面、能买得起设备、能接触上层采购
比下环居民过得好，但不是统治阶层
对下环的苦难有距离感，也有赚钱的机会
```

玩家不会因为“见死不救”被系统惩罚。

NPC 不会对玩家讲道理。

剧情只呈现：

```text
谁在买
谁在卖
谁付得起
谁被留在污染里
```

玩家自己决定要不要赚这笔钱。

## 1. 基调

### 1.1 一句话

```text
一个开在太空站夹层里的化学店主，
看着上层买纯度，下层买活路，
自己靠把脏液体变干净赚钱。
```

### 1.2 三条基调支柱

#### 支柱一：纯度是阶级

- 上层采购只要低化学残留、低重金属。
- 下环诊所、黑市、劳工食堂只能买剩下的。
- 玩家不评价这个分配，只决定把货卖给谁。

表现方式：

```text
同一瓶酸，上层采购出 3 倍价，薇拉只出基础价。
不是“好人/坏人”，是预算不同。
```

#### 支柱二：机器比人可靠

- 奥雅不关心玩家把机器用来做什么。
- 她只关心机器有没有被用好、会不会砸自己招牌。
- 玩家与奥雅的关系是“供货商—熟客”，不是师徒救赎。

表现方式：

```text
奥雅介绍成型机，只讲耗电、配方、产量、价格。
不讲“这台机器能拯救谁”。
```

#### 支柱三：黑暗是背景，不是任务

- 太空站有停水、污染、裁员、黑市、安检、债务。
- 这些事通过客户、广播、价格和退货表现。
- 玩家可以从中赚钱，也可以绕开。
- 没有“拯救下环”主线。

表现方式：

```text
薇拉说诊所最近缺货，但她不请求玩家捐款。
她只是把收购价压低，然后问玩家卖不卖。
```

### 1.3 叙事规则

```text
不写“正确选择”
不写“善良的玩家”
不让 NPC 感谢玩家的道德
不把黑暗当成玩家的个人创伤
不用长篇解释机制
让价格、库存、退货、准入说话
```

```text
玩家是“在场者”，不是“救世主”。
黑暗通过生意流动，而不是通过任务宣讲。
```

## 3. 本 Mod 机制如何在剧情里被用上

### 3.1 净化装置：原版做不到的定向去除

原版没有稳定、定向去除化学污染和重金属的手段。

本 Mod 的净化装置可以做到：

```text
化学污染 → 去除
重金属   → 去除
温度影响净化下限
```

剧情用途：

```text
上层采购只要低化学残留的酸。
普通商人做不到，玩家可以。
```

这不是教学，是订单：

```text
“化学残留低于 1%，上层才收。”
“你这套净化塔能做到，我要 100 mL。”
```

### 3.2 离心机/冷萃：处理净化拿不掉的东西

净化只解决化学污染/重金属。

塑料、矿物、物理碎屑需要离心/冷萃。

剧情用途：

```text
薇拉的低价原料含各种污染物；
玩家要接她的单，就必须有分离手段。
```

不是“奥雅教玩家”，而是：

```text
薇拉：“你这酸有沉淀，诊所不要。”
玩家自己发现净化不够，再去奥雅货里找离心机。
```

### 3.3 成分成型机：把纯度变成产品

成型机把纯化后的液体按配方压成化学产物，消耗电量。

这给玩家一个“从卖原料到卖产品”的升级理由：

```text
酸/碱原料 → 成型机 → 助熔剂/化学产品 → 更高单价
```

剧情用途：

```text
奥雅把成型机放进自己的库存；
玩家可以买，也可以不买；
买了以后，采购客户开始问“有没有成品”。
```

### 3.4 交易与退货：让选择有商业后果

原版有化学品退货/客户反馈逻辑。

可以用它表现：

```text
卖给上层的货被检出化学残留
→ 退货/赔款/信誉下降
```

不需要道德审判。

玩家承担的是：

```text
钱
信誉
采购准入
```

## 4. 前期 7 天

目标：

```text
第一天就能开始
7 天内让玩家用上净化、分离、成型机中的至少两条线
不靠道德任务推动
```

### Day 1：奥雅教程（现有）

保留现有 95% 酸教程。

只改语气：

```text
奥雅不夸玩家“有天赋”。
她只确认机器能跑、酸能达标，然后把样品收走。
```

### Day 2：站务采购员

一个临时访客，不是常驻 NPC。

身份：

```text
站务采购/化验采样员
代表上层机构收购低化学残留化学品
偶尔来，不是每天来
```

剧情：

```text
“上层要一批低化学残留的酸。”
“净化塔做不到，我知道。你这套设备能。”
“100 mL，99% 以上，化学残留低于 1%。做得到，价格好说。”
```

玩家选择：

```text
A. 卖
   拿高价，缓解前期经济压力
B. 不卖，留着自己用
   采购员离开，之后还有机会
C. 追问用途
   采购员不解释，只重复规格
```

奖励：

```text
基础价 2.5–3 倍
足够覆盖第一次设备升级/租金
```

设计目的：

```text
让玩家第一次感到：
“我的净化装置不是玩具，是能换钱的工业能力。”
```

### Day 3：薇拉的低价单

薇拉照常来收酸/碱，但价格低。

剧情：

```text
“诊所的预算就这么多。”
“你卖给上层是卖，卖给我也是卖。”
“我不问你用什么原料，你也别问我拿去做什么。”
```

玩家选择：

```text
A. 接低价单
   稳定现金流，薇拉关系+
B. 拒绝，留给上层采购
   现金多，薇拉关系-
```

设计目的：

```text
不是“救诊所”或“不救诊所”。
是两个客户抢同一批货。
```

### Day 4：奥雅的成型机

奥雅第二次/第三次到访时，展示新机器。

剧情：

```text
“我自己改的。成分成型机。”
“把纯化后的液体按配方压成成品。耗电，配方在机器里。”
“今天起放我货里。买不买随你。”
```

效果：

```text
一次性剧情
把 fluxforge_chemical_former 加入奥雅库存
不免费送
玩家可以买，也可以继续卖原料
```

设计目的：

```text
用“供应商上新”介绍机制；
不用教程弹窗；
不强迫玩家改变玩法。
```

### Day 5：停水/污染警报

太空站广播/客户闲聊：

```text
“下环水处理延迟。”
“不要直接饮用未过滤水。”
“上层区供应正常。”
```

商业影响：

```text
薇拉的原料变脏
采购员对化学残留更挑剔
净化装置价值上升
```

玩家选择：

```text
A. 提高售价
   现金+，薇拉/下环客户关系-
B. 维持原价
   关系+，现金少
C. 停卖，先保证自己的库存
   安全，但少赚
```

没有“正确”选项。

### Day 6：成型机第一单

如果玩家买了成型机：

```text
采购员：“上次的酸不错。有没有助熔剂成品？”
奥雅：“他说的就是成型机做的东西。”
```

玩家目标：

```text
用成型机做一批 flux_agent
```

如果玩家没买：

```text
采购员只收原料，价格低一档
奥雅不劝，只报机器价格
```

设计目的：

```text
成型机是可选的升级，不是主线门槛；
但买了会打开更高单价的产品线。
```

### Day 7：结算

- 房租/维护费扣除。
- 采购员留下下次收购意向。
- 薇拉根据关系调整订单。
- 奥雅根据是否购买成型机调整库存/台词。

玩家获得：

```text
第一次经济缓冲
对三条路线的初步选择：
  原料供应
  上层采购
  成品制造
```

## 5. 站务采购员：具体设计

### 5.1 访客性质

```text
ID: station.procurement
身份: 站务采购/化验采样员
立绘: 复用原版上层/职员/拾荒者立绘（不新增素材）
到访: 低概率，非每日
```

参考原版鉴定客户：

```text
临时访客
随机出现
有预算/需求
不进入固定剧情队列
```

不是原版鉴定服务的复制，而是借用它的“偶发临时客户”节奏。

### 5.2 到访规则

```text
Priority 30
Chance 0.35
Cooldown 3 天
Condition: Day >= 2
VisitKind.Buy
```

首次出现可以 100% 触发，后续恢复概率。

### 5.3 收购要求

```text
酸或碱
浓度 >= 99%
化学污染 + 重金属 <= 1%
数量 100–250 mL
```

价格：

```text
基础价的 2.5 倍
浓度 >=99.5% 时 3 倍
化学残留超标：拒收，但留下下次机会
```

### 5.4 对话气质

```text
不解释机构
不感谢玩家
不关心玩家困难
只关心规格、数量、交货时间
```

示例：

```text
“99%，化学残留低于 1%。”
“做不到就说做不到，我没时间听过程。”
“上层只收这个标准。下层用什么，不归我管。”
```

### 5.5 为什么能缓解经济压力

```text
一次采购的利润 ≈ 玩家早期几天的基础收入
出现频率低，不会取代薇拉
让玩家有动力保留净化装置、升级温度控制
```

### 6.1 触发

```text
NPC: 奥雅
Trigger: VisitStarted
Priority: 85
Condition: HasSecondVisit && !oya.former_introduced
```

### 6.2 内容

```text
奥雅把机器放在柜台上，没有包装。

“纯化后的液体按配方压成成品。耗电，配方在机器里。”
“今天起放我货里。买不买随你。”

玩家选项：
  1. “多少钱？”
  2. “它能做什么？”
  3. “我先看看。”
```

### 6.3 效果

```text
flag: oya.former_introduced
奥雅库存加入 fluxforge_chemical_former
```

```text
  奥雅：“配方别乱改。炸了别说是我的机器。”
玩家没买：
  采购员只收原料，价格低一档
  奥雅不催
```

## 8. 玩家可做的商业选择

### 8.1 卖给谁

```text
上层采购：高价，要求低化学残留
薇拉：低价，收得杂，稳定
自用：留原料给成型机
```

### 8.2 是否升级

```text
净化 → 达到上层标准
离心/冷萃 → 处理复杂原料
成型机 → 从原料转向成品
```

### 8.3 是否冒险

```text
把含沉淀的货卖给薇拉
→ 退货/赔款/关系下降
把低残留货留给上层
→ 薇拉缺货，关系下降
停水期间涨价
→ 现金增加，客户流失
```

这些选择没有“道德正确”提示。

## 9. 技术落点

不需要新引擎。

```text
临时采购员 = 一个新 NpcStoryContent
到访 = VisitRule（chance/cooldown/condition）
收购 = 参考 AcidBuyerTrade 的柜台扫描逻辑
成型机介绍 = StoryEvent + 剧情动作
加入奥雅库存 = 现有 AddDirectSellingItemToTable / 库存逻辑
停水/抽检 = flag + 日常事件条件
```

注意：

```text
原版没有稳定的定向化学/重金属去除；
这正是玩家用净化装置赚钱的差异点。
采购员的规格要围绕这个差异设计。
```

上一版中的以下内容不再使用：

```text
薇拉的姐姐/诊所救援主线
揭发北环
召回问题货的道德抉择
“最佳结局”/“善良结局”
14 天三幕道德弧线
玩家被要求关心陌生人
```

保留但改成商业事件：

```text
化学品退货 → 赔款/信誉/准入
采购员 → 偶发高价客户
成型机 → 奥雅库存上新
停水/污染 → 价格与需求变化
```

## 11. 验收标准

```text
1. 玩家完成奥雅教程后，第二天有机会遇到站务采购。
2. 采购员的要求能用净化装置完成，且利润明显高于薇拉。
3. 采购员不是每天出现，不取代薇拉的基础现金流。
4. 奥雅介绍成型机时只讲功能/价格，不强制购买。
5. 成型机在介绍后出现在奥雅库存。
6. 玩家不买成型机也能继续经营，只是少一条产品线。
7. 停水/污染事件只改变价格/需求，不弹出道德选择。
8. 卖给薇拉问题货会产生退货/赔款，而不是“善恶判定”。
9. 玩家可以选择只赚钱、不帮助任何人，剧情不训斥玩家。
10. 所有新增剧情文本不出现“你应该”“正确”“善良”等说教词。
```
