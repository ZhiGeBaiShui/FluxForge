# 合同固定星期调度

原版星期计算依据：`.tmp-decomp/StoreCalendar.cs` 的 `GetDayOfWeek()` 使用 `dayCounter % 7`，1为星期一，4为星期四。

签约日为D：首次收货D+7，此后只在与D相同的星期收货；首次送料D+3，此后只在与D+3相同的星期送料。判断使用首次约定日与当前日的模7关系，不以距上次到访的天数决定。

跳天错过的日期不补发、不补收；例如周一签约，跳到周五不会补周四送料，下一次只在周一收货或周四送料。两项业务不再同时“逾期”，已删除原先按最后处理日期仲裁的代码。

合同有效期间不再使用签约前的普通薇拉7天来访规则；100声望任务的独立空闲日邀请仍保留。合同终止后可沿用普通散卖规则。

保留最后一次送料/收货日期，用于防止同一约定日重复处理；调用依据是VisitRule与StoryEvent都会检查业务日期，处理完成后也可能再次查询。未新增跳天兼容补丁、计时器或状态迁移。下次约定日期由签约日与最后处理日计算，不再写入冗余next_day字段。

测试覆盖周一签约的正常日、跳过送料日、跨多周跳天、同日已处理后不重复、普通7天规则不会在合同空闲日触发。旧的逾期仲裁测试替换为固定星期测试。
