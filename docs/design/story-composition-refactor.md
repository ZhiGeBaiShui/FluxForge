## 防御判断依据

| 判断 | 实际路径/必要性 |
|---|---|
| BuildNext的_cancelled与Do回调取消检查 | 原版PlayerStore.EndNight强制Dismiss，OnDismiss接Cancel；InterruptDialog会执行当前行endAction，因此必须阻止尚未执行的赠礼/动作 |
| 帧栈为空 | 根图结束与子图返回的正常控制流，只有根结束通知Host |
| Sequence为null | 初入边或选中另一条边后尚未注册步骤；Select显式清空，Register显式赋值 |
| frame.Next不为空 | 对应图中的玩家选择暂停状态，不是节点缺失兜底 |
| PendingInsertion/候选为null | 当前没有插入调度或正常无匹配内容，继续父步骤 |
| 有/无Dialogue尾行 | Do在上一行结束执行或无行时立即执行；Call/Insert必须等待已有对白结束后进入 |
| frame.Event非null | 已注册事件需要记SeenCount，直接Call普通子图和根图没有注册事件身份 |
| call.Context ?? frame.Context | 直接子调用继承上下文；生命周期交易阶段显式携带TradeResult。两种均有生产调用方，不是依赖缺失回退 |
| point/条件/次数/互斥检查 | 复用原选择器业务规则，防止不同插入点混播 |
| bridge的返回结果 | 根正常结束允许返回null，原版SetCurrentDialog直接赋值；专项审计已删除冗余next非空判断，桥仍不作为对白显示 |
| 交易结果/阶段候选不存在 | 可没有交易后事件或离场事件，这是原Host原有正常分支 |

未加最大递归深度、循环上限、参数null修复、缺定义静默跳过、catch全部异常、
自动重试、动作visited集合、多NPC锁或猜测存档迁移。
父游标前进自然保证返回不重放业务；插入游标单次遍历自然保证无限次片段不会卡在本次点循环。
