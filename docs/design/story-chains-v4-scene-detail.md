## 0. 统一规则

### 0.1 邀请

剧情邀请是普通客户：

```text
dismissable = true
玩家不接待，他自己走
走掉 = declined
不扣钱、不扣关系、不写后续
```

NPC 不说：

```text
“有件事想跟你谈。”
```

只说交易：

```text
“99% 酸，低残留，100 mL。你有设备。”
```

### 0.2 拒绝

每个入口至少有一个：

```text
“这批不做。”
```

每个中途节点至少有一个：

```text
“到此为止。”
```

拒绝后台词是交易性收尾：

```text
“行。要货的时候再来。”
```

不是：

```text
“行。”（赌气）
“你会后悔的。”（威胁）
“你错过了机会。”（说教）
```

### 0.3 链槽

```text
每个 NPC 最多一条 active 链
全局最多两条
挂起的邀请 pending，不按日期过期
```

### 0.4 当前经济基准

```text
薇拉收购：99% 酸/碱，基础价约 10 信用点 / 100 mL
采购员：基础价 2.5 倍左右
成型机：fluxforge_chemical_former，300 信用点，1 电/次
助熔剂配方：100% 重金属 4 mL → 1 个 flux_agent
```

## 1. chain.procurement：上层采样

### 1.1 触发

```text
玩家完成第一次 99% 酸交易后
下一次开门，站务采样员出现
```

不是固定 Day 3。

### 1.2 场景 1：柜台

站务采样员穿站务制服，站在柜台前，没有寒暄。

```text
“99% 酸，化学残留低于 1%，100 mL。”
“上层只收这个标准。”
“你有净化设备。做得到，价格好说。”
```

玩家选项：

```text
1. “什么价？”
2. “这批不做。”
3. “你怎么知道我有设备？”
```

选 3：

```text
“你的出货记录里，化学残留比别家低。”
“我不关心你怎么做到的。”
```

选 2：

```text
“行。要货的时候再来。”
```

链结束，无惩罚。

### 1.3 场景 2：交货

下一次采样员到访。

如果玩家有 100 mL、99% 以上、化学残留低于 1% 的酸：

```text
他只看数据，不看玩家。
“可以。”
“以后每 7 天，100 mL。价格按长期供应算。”
```

玩家选项：

```text
1. 接长期供应
   单价 +10%，每 7 天固定 100 mL
2. 只做这一次
   本次 +30%，后续概率降低
3. 到此为止
   本次不交，链结束
```

如果玩家没有合格货：

```text
“没有就下次。”
他离开，链保持 pending。
```

不扣钱，不催。

### 1.4 场景 3：长期或单次

如果接长期：

```text
获得 flag: chain.procurement.longterm
每 7 天采购员优先来
```

如果单次：

```text
获得本次高价
flag: chain.procurement.once
后续采购概率降低，但不是零
```

### 1.5 机制

```text
需要新增“采购员收购”内容：
扫描后柜台
检查酸/碱浓度 >=99%
检查 chemical + heavy <=1%
支付高价
```

不是复用薇拉交易，但复用她的柜台扫描模式。

## 2. chain.vera_supply：低价供货

### 2.1 触发

玩家主动向薇拉报价：

```text
“诊所缺货的话，我可以固定供。”
```

或完成一次批量交易后，薇拉主动提。

### 2.2 场景 1：报价

```text
薇拉：“预算低。你卖上层是卖，卖我也是卖。”
“99% 酸，100 mL，每 3 天一批。”
“价格按基础价，不按上层价。”
```

玩家选项：

```text
1. “可以，但先付一半。”
2. “这个价我不做。”
3. “我能供，但量不固定。”
```

选 2：

```text
“行。有货再找我。”
```

链结束，无惩罚；薇拉日常收购照常。

选 1：

```text
预付款 +50
flag: chain.vera_supply.prepay
```

选 3：

```text
无预付款
flag: chain.vera_supply.flexible
```

### 2.3 场景 2：连续供货

下一批交付时，薇拉检查数量。

```text
“这批可以。”
“下环最近不太平。你能固定供，我就把长期单给你。”
```

玩家选项：

```text
1. 保供：单价 -10%，关系 +1
2. 涨价：本批 +30%，关系 -1
3. 到此为止：不再供，关系不变
```

### 2.4 场景 3：短缺

如果站台短缺事件发生，薇拉来：

```text
“诊所预算没涨，但外面在涨价。”
“你按哪个价给我？”
```

玩家选项：

```text
1. 维持合同价
   现金不变，关系 +1
2. 按短缺价
   现金 +25%，关系 -1
3. 停卖
   库存保留，关系不变
```

没有“病人需要”的台词。

### 2.5 机制

```text
需要给薇拉增加 contract flag：
  chain.vera_supply.low_price
  chain.vera_supply.relationship
现有收购逻辑只按浓度定价，需要合同价覆盖。
```

```text

“成品我按 200 收。原料我按 80 收。”

```

玩家选项：

```text

```

选 2：

```text
采购员收原料，价格 80。

```

选 3：

```text
“行。原料也收。”
```

如果玩家用成型机做出 flux_agent：


## 4. chain.return：退货

### 4.1 触发

玩家在短缺/赶工场景中卖出一批未复检的酸：

```text
浓度 98.5%，化学残留 1.5%
薇拉因缺货收下
flag: batch.tainted
```

这个前置必须由内容动作产生，否则链永远不触发。

### 4.2 场景 1：柜台

第二天，薇拉把瓶子放回柜台。

```text
“这批有沉淀。”
“诊所不要。”
“你说怎么办。”
```

玩家选项：

```text
1. 退款
   现金 -80，关系不变，链结束
2. 换货
   库存 -1 批，关系 +1，链结束
3. 按合同走
   现金不变，关系 -1，链结束
4. 到此为止
   不处理，关系 -1，链结束
```

不写：

```text
“拒绝负责”
```

### 4.3 场景 2：后续

如果选退款或换货：

```text
薇拉：“下次别赶。”
没有长篇道德。
```

如果选按合同走：

```text
薇拉：“行。以后你的货我验得细一点。”
```

关系 -1，后续收购更严格，但不是永久封杀。

### 4.4 机制

```text
需要一个“赶工交付”动作：
允许 98% 以上但未复检的批次进入交易
写 batch.tainted
```

没有这个前置，return 链不成立。

## 5. chain.inspection：抽检

### 5.1 触发

玩家风险值 >=1，或主动去站务窗口查记录。

### 5.2 场景 1：检查

检查员站在柜台前，拿着记录板。

```text
“最近三天的出货记录。”
“有人举报你卖未登记化学品。”
```

玩家选项：

```text
1. 配合
2. 贿赂 300
3. 给站长办公室打电话
   500，或消耗 1 次人情
4. 关门，改天再说
```

### 5.3 后果

```text
配合：固定罚款 150，风险 0
贿赂：现金 -300，风险 +1
打电话：现金 -500 或人情 -1，检查取消
关门：当天营业损失，固定 5 天后必回，风险不涨
```

人情来源：

```text
完成一次 procurement 链 +1
最多存 2 次
```

### 5.4 场景 2：检查后

如果配合：

```text
“这次罚款。下次记录做干净。”
检查员离开。
```

如果打电话：

```text
“站长说这次算了。”
“下次别让我难做。”
检查取消，风险不变。
```

没有道德评价。

### 5.5 机制

```text
风险 0–3 用 flag 存
不新增检查模拟
用原版安全检查的访客/对话外壳
```

```text

```

### 6.2 场景 1：问

```text
奥雅：“旧厂拆出来的。”
“能用就行，问那么多干什么。”
```

玩家选项：

```text
1. 继续问
2. 不追问
3. 只谈买卖
```

选 2/3：

```text
奥雅：“行。”
当场给一句有用的话：
  “别买北环的酸。他们的重金属下不去。”
```

获得信息 +1，链结束，不影响经营。

### 6.3 场景 2：继续问

```text
奥雅：“北环水处理厂。以前给全站供酸。”
“后来他们发现，纯度高一点，能多卖三倍。”
“至于剩下的东西去哪了，没人问。”
```

玩家选项：

```text
1. “你有旧厂的渠道？”
2. “我不想掺和。”
3. “到此为止。”
```

选 1：

```text
奥雅给一个名字/供应商地址。
信息 +1。
```

选 2/3：

```text
“行。机器坏了再找我。”
```

链结束。

### 6.4 场景 3：旧厂渠道

```text
奥雅：“那个人现在还在卖原料。你要的话，我帮你问。”
```

玩家选项：

```text
1. 要渠道
   解锁受限化学品来源 flag
2. 不要
   链结束
```

### 6.5 机制

```text
信息 +1 / +1 用 flag 存
不新增物品
“渠道”只作为 black_market 的触发条件
```

```text
“上层要签独家。”
“签了，你的货只能走我们。”
“价格 +15%，量稳定。”
```

玩家选项：

```text
1. 签
2. 不签
3. 买非独家配额 800
4. 到此为止
```

### 7.3 后果

```text
签：
  采购价 +15%
  薇拉/黑市订单 -50%
  flag: chain.upper_contract.exclusive

不签：
  采购价不涨
  无优先配额
  薇拉/黑市照常
  和“到此为止”相同，无额外惩罚

买配额：
  现金 -800
  采购价 +8%
  保留全部渠道
  约 40 次交付回本
```

### 7.4 场景 2：签后

如果签：

```text
“合同从明天开始。”
“你的薇拉单子，自己处理。”
```

薇拉下一次来：

```text
“听说你签了上层。”
“以后我的单，你接不接？”
```

玩家选项：

```text
1. 继续偷偷供
   风险 +1，薇拉关系 +1
2. 停供
   薇拉关系 -1
3. 到此为止
   不解释
```

### 7.5 机制

```text
采购价 + 渠道限制是内容 flag
不改原版商店
```

```text

   薇拉：“行。”

   信息 +1，薇拉警惕
```

### 8.3 场景 2：中间人

如果选中中间人：

```text
薇拉：“你只抽成，送货的人我找。”
“出了事，你别说认识我。”
```

```text
1. 成交
   现金 +80
2. 到此为止
```

如果信息 >=2：

```text
薇拉给一个具体买家名。
```

```text

不新增犯罪系统
```

```text
需要终端/挂单 UI。

24–48 小时后有人来，或没人来。
```

