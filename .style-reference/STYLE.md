# 原版贴图风格参考

来源：图片扒取完整版.zip，共940张PNG。已解码全量图片并通过4张联系表进行视觉总览；小型图集与字体图集尚未逐个放大分析。后续针对具体资产应重新读取对应原图，不能仅凭缩略图生成。

## 后续出图约束
- 以原图为视觉参考：复古像素美术、低分辨率游戏资产，克制的工业科幻与生活化旧物气质。
- 主色为暗紫、灰蓝、低饱和青绿，搭配米黄、旧纸色、锈橙和暗红。高亮常见浅黄、青色；不要整体变成高饱和霓虹。
- 人物采用正面或轻微偏转半身像，比例偏写实，以色块和离散像素表达脸部、衣物褶皱与磨损；避免光滑3D和动漫大眼。
- 物品轮廓清楚，有限明暗层次；金属、纸张、食物等保留各自质感。保持原版像素颗粒与细节密度。
- UI使用深紫底、细线边框、切角和双线装饰；青色普通态、淡黄色高亮在多组按钮中重复出现，具体状态以对应原图为准。
- 文件、票据、标签用旧纸色、不齐边缘、轻微磨损；不应给所有资产统一添加严重脏污。
- 场景为细密的像素环境，偏暗，局部冷暖灯光；不采用照片或现代扁平矢量风格。
- 包内还含字体SDF图集、遮罩、纯色块、品牌图标等技术资产，不把它们当作统一美术样本。
- 生成前匹配同类原图的尺寸、视角、透明背景、轮廓、光照和状态变体；生成后对照原图检查。需要保持精确像素与尺寸时，输出还需做像素级验收。
